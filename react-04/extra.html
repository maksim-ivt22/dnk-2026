Задача

Основной планировщик уже работает. Теперь добавь дополнительные возможности.

Нужно добавить:
  1. приоритет задачи;
  2. статистику;

1. Добавь priority

Новая задача: 

{
    id: Date.now(),
    title: title,
    completed: false,
    priority: priority
}

2. Создай state

const [priority, setPriority] =
    useState("normal");

5. Статистика

Всего задач: 

const total = tasks.length;

Выполнено: 

const done =
    tasks.filter(
        task => task.completed
    ).length;

Осталось: 

const active =
    tasks.filter(
        task => !task.completed
    ).length;

6. Покажи статистику

<div>

    <p>
        Всего: {total}
    </p>

    <p>
        Выполнено: {done}
    </p>

    <p>
        Осталось: {active}
    </p>

</div>

7. Очистить выполненные

function clearCompleted() {

    setTasks(

        tasks.filter(
            task => !task.completed
        )

    );

}

Кнопка: 

<button
    onClick={clearCompleted}
>
    Удалить выполненные
</button>

8. localStorage

Сейчас после обновления страницы добавленные задачи исчезают.

Браузер умеет хранить небольшие данные: 

localStorage

9. Сохраняем задачи

useEffect(() => {

    localStorage.setItem(
        "tasks",
        JSON.stringify(tasks)
    );

}, [tasks]);

10. Что такое JSON.stringify?

localStorage хранит строки.

Поэтому массив превращаем в строку: 

JSON.stringify(tasks)

11. Получаем сохранённые задачи

const savedTasks =
    localStorage.getItem("tasks");

Если они есть: 

JSON.parse(savedTasks)

12. Начальное значение useState

const [tasks, setTasks] = useState(() => {

    const saved =
        localStorage.getItem("tasks");

    return saved
        ? JSON.parse(saved)
        : [];

});
После этого добавленные задачи смогут оставаться даже после обновления страницы.

13. Важный момент

Если используешь localStorage, подумай: нужен ли теперь первоначальный fetch при каждом запуске.

Один из вариантов: 

если localStorage пуст
↓
загрузить API

если задачи уже сохранены
↓
использовать localStorage

14. Очистка всех задач

function clearAll() {

    if (
        confirm(
            "Удалить все задачи?"
        )
    ) {

        setTasks([]);

    }

}
