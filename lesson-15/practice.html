```html Практика №15 — Git и GitHub

Практическая работа №15

Создаём Git-репозиторий и загружаем проект на GitHub

Задача

Возьми один из своих готовых сайтов или React-проект.

Нужно создать Git-репозиторий, сделать несколько commit и загрузить проект на GitHub.

В конце работы должно быть:
  • локальный Git-репозиторий;
  • репозиторий на GitHub;
  • минимум 3 commit;
  • проект загружен на GitHub;
  • понятные сообщения commit.

1. Открой проект

Открой папку проекта в VS Code.

Затем открой терминал.

2. Проверь Git

git --version

Если отображается версия, Git установлен.

3. Создай репозиторий

git init

4. Проверь состояние

git status
Посмотри, какие файлы Git показывает как новые.

5. Добавь файлы

git add .

6. Снова проверь status

git status

Сравни результат с предыдущим git status.

7. Сделай первый commit

git commit -m "Добавил начальную версию проекта"

8. Измени проект

Добавь в сайт новый заголовок или новый раздел.

Например: 

<section>

    <h2>
        Новый раздел
    </h2>

    <p>
        Этот раздел добавлен после первого commit.
    </p>

</section>

9. Посмотри изменения

git status

10. Второй commit

git add .

git commit -m "Добавил новый раздел"

11. Сделай третье изменение

Например:

  • измени цвет;
  • добавь ссылку;
  • добавь карточку;
  • исправь текст.

12. Третий commit

git add .

git commit -m "Обновил оформление сайта"

13. Посмотри историю

git log --oneline

Должно быть минимум три commit.

--oneline показывает историю в коротком виде.

14. Создай репозиторий на GitHub

На GitHub создай новый репозиторий.

Название, например: 

my-web-project
Если локальный проект уже содержит файлы, не добавляй при создании GitHub-репозитория дополнительные README или другие файлы. Так первый push будет проще.

15. Подключи GitHub

Скопируй адрес своего репозитория. 

git remote add origin АДРЕС

Например: 

git remote add origin https://github.com/username/my-web-project.git

16. Назови основную ветку main

git branch -M main

17. Отправь проект

git push -u origin main

18. Проверь GitHub

Обнови страницу репозитория.

Проверь:

  • есть ли файлы;
  • видна ли история commit;
  • правильное ли название проекта.

19. Сделай ещё одно изменение

После первого push измени любой файл.

20. Отправь обновление

git status

git add .

git commit -m "Добавил финальные изменения"

git push
Обрати внимание: теперь команда 
git push
работает без дополнительных параметров.

21. Если это React-проект

Проверь наличие файла: 

.gitignore

В нём должна быть исключена папка: 

node_modules/
Не загружай node_modules на GitHub.

Проверка

Есть Git-репозиторий

Выполнен git init

Использован git status

Использован git add

Есть минимум 3 commit

Сообщения commit понятные

Есть репозиторий на GitHub

Добавлен remote origin

Основная ветка называется main

Выполнен первый push

После изменения выполнен ещё один push

Файлы видны на GitHub

Готово?

Покажи преподавателю:

  1. проект в VS Code;
  2. git log --oneline;
  3. репозиторий на GitHub.

После проверки переходи к Extra.

```
