Bootstrap

Результат занятия

Вы создадите адаптивную страницу школьных кружков с помощью Bootstrap: подключите библиотеку, расположите карточки в сетке, оформите навигацию и форму. Сравните результат со страницей на Grid из занятия №7.

Понадобятся редактор кода, браузер, интернет для загрузки библиотеки и знания HTML, CSS, Flexbox и адаптивной вёрстки.

Дополнительное задание выполняется после основной работы и не входит в эти 180 минут.

Что даёт Bootstrap

Bootstrap — библиотека готовых CSS-стилей и JavaScript-компонентов. Её классы помогают оформить кнопки и формы, задать отступы и построить адаптивную сетку. HTML по-прежнему описывает содержание страницы; собственный CSS можно подключать для оформления проекта.

На занятии используется Bootstrap 5.3.9. В практике библиотека подключается по CDN: браузер загружает файлы по интернету. Для работы без интернета можно заранее скачать файлы с официальной страницы загрузки и подключить локальные копии.

CSS нужен для внешнего вида и сетки. Кнопки, которые раскрывают меню или блок, дополнительно используют JavaScript Bootstrap. Обычная ссылка или кнопка со стилем btn не требует JavaScript библиотеки.

Контейнер, строка и колонки

container ограничивает и центрирует содержимое. Внутри него row объединяет колонки, а классы col-* задают их ширину. Обычная сетка Bootstrap основана на Flexbox и делит строку на 12 условных долей.

<div class="container">
  <div class="row g-3">
    <div class="col-12 col-md-6 col-lg-4">Первая карточка</div>
    <div class="col-12 col-md-6 col-lg-4">Вторая карточка</div>
    <div class="col-12 col-md-6 col-lg-4">Третья карточка</div>
  </div>
</div>

На узком экране col-12 занимает всю строку. С 768 px класс col-md-6 отводит колонке половину строки, а с 992 px col-lg-4 — треть. Классы срабатывают от указанной ширины и выше, пока их не переопределит следующий. g-3 задаёт промежутки между колонками и строками.

Это другой способ получить адаптивные колонки: в прошлом занятии вы сами задавали CSS Grid и media queries, а здесь используете готовые правила Bootstrap.

Готовые компоненты и отступы

<article class="card h-100">
  <div class="card-body">
    <h2 class="card-title h5">Робототехника</h2>
    <p class="card-text">Собираем модели.</p>
    <a class="btn btn-primary" href="#contacts">Как записаться</a>
  </div>
</article>

card оформляет карточку, card-body добавляет внутренние отступы, а h-100 помогает карточкам в одной строке занять высоту своих колонок. У заголовка тег h2 сохраняет смысл, а класс h5 меняет его размер.

Служебные классы задают отдельные свойства: mt-3 — верхний внешний отступ, py-4 — внутренние отступы сверху и снизу, text-center — выравнивание текста. Числа в классах отступов — ступени шкалы Bootstrap, а не количество пикселей.

Формы и собственный CSS

Для поля используйте form-control, а для подписи — form-label. Свяжите label с полем через одинаковые значения for и id. Внешний вид формы сам по себе не отправляет данные: для настоящей отправки нужна отдельная обработка.

Чтобы изменить оформление, подключите свой CSS после Bootstrap. Например, создайте класс club-hero и задайте ему фон. Старайтесь выбирать осмысленные имена собственных классов, чтобы их было легко найти.

Самопроверка: сколько карточек в строке на ширине 800 px в примере выше?

Две: действует col-md-6. При 375 px будет одна, при 1200 px — три.
