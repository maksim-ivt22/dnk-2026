Занятие №6 · Практика

Flexbox

Задача

Сверстайте расписание из трёх карточек. На широком экране карточки должны помещаться в один ряд, а при сужении окна — переноситься на следующую строку.

1. Соберите расписание

Создайте файл schedule.html. Перенесите в него разметку расписания из теории. Внутри каждой карточки оформите название предмета заголовком h2, а время начала занятия укажите в абзаце.

2. Настройте раскладку

В элементе style задайте контейнеру гибкую раскладку с переносом, промежутком 16px и центрированием по главной оси. Каждой карточке задайте flex-basis: 180px, внутренний отступ 12px и видимую границу.

3. Проверьте результат

Откройте файл в браузере. На широком экране три карточки должны образовать один ряд. Сужайте окно до появления второй строки. Убедитесь, что последняя карточка расположена по центру, а порядок занятий совпадает с разметкой.

4. Эксперимент с шириной

В инструментах разработчика выберите элемент расписания. Временно задайте ему ширину 580px и используйте у карточек box-sizing: border-box. Три карточки по 180px и два промежутка по 16px займут 572px. Уменьшите внутреннюю ширину до 570px. Запишите, какая карточка перенеслась и почему двух пикселей оказалось достаточно для изменения раскладки.

5. Исправьте ошибку в селекторе

.schedule article { display: flex; }

Ученик применил только это правило и ожидал увидеть три предмета в один ряд. Определите, какие элементы теперь участвуют в гибкой раскладке.

Разбор

Контейнером стала каждая статья. Её заголовок и абзац расположатся рядом, а сами статьи останутся одна под другой. Перенесите display: flex на .schedule.

6. Сверстайте главную страницу кружка

Расписание уже готово. Теперь превратите его в часть сайта «Мастерская». Создайте рядом с schedule.html файл club.html и отдельный файл club.css. Добавьте в head новой страницы эти строки:

<meta name="viewport" content="width=device-width, initial-scale=1">
<link rel="stylesheet" href="club.css">

Используйте схему как макет. Рамки обозначают области страницы. В HTML сначала запишите содержимое в порядке чтения, затем оформите каждую область отдельно.

Контакты                                   Наверх
  1. Создайте шапку header, основную часть main и нижнюю часть footer. Дайте разделам уникальные id и свяжите пункты меню с ними через href="#расписание" и аналогичные ссылки.
  2. В шапке сделайте два непосредственных дочерних элемента: название и nav. Расположите их у противоположных краёв. Затем расположите ссылки внутри nav в строку с равными промежутками. Для этого понадобятся два отдельных flex-контейнера.
  3. Добавьте описание кружка своими словами. Перенесите расписание в main и расширьте его до шести карточек. В каждой укажите название, день и время. Дайте одному кружку длинное название.
Если расстояния появились между названием и меню, но не между ссылками

Проверьте родителя ссылок. Свойство gap на header управляет расстоянием между названием и nav. Чтобы разделить ссылки, примените display: flex и gap к самому nav.

7. Подберите размеры по макету

Ограничьте внутреннюю ширину расписания до 900px. При промежутке 18px вычислите ширину каждой из трёх одинаковых карточек. Запишите вычисление, затем задайте результат через flex-basis. Включите box-sizing: border-box, добавьте границу и padding. Проверьте, что в первом ряду остаются три карточки.

Сверить расчёт

В ряду два промежутка. На карточки остаётся 900 − 2 × 18 = 864px, то есть по 288px. Проверьте внутреннюю ширину контейнера, если третья карточка переносится раньше.

Сузьте окно до двух колонок. Разрешите карточкам расти и сравните результат с фиксированной шириной. Уберите одну карточку, посмотрите, как выглядит неполный ряд, и выберите вариант для своей страницы. Верните шестую карточку.

8. Адаптируйте шапку для телефона

В узком окне название и меню могут столкнуться. Вертикальная шапка даст меню отдельную строку. Подставьте в пример свой класс шапки и проверьте, как изменилось направление осей.

@media (max-width: 600px) {
  .club-header {
    flex-direction: column;
    align-items: flex-start;
  }
}

Разрешите перенос ссылок внутри nav. Проверьте страницу при ширине 360, 600 и 1000px в режиме устройств инструментов разработчика. Для каждой ширины запишите число карточек в первом ряду и положение меню. Убедитесь, что контакты доступны по ссылке и для чтения страницы не требуется горизонтальная прокрутка.

9. Проверьте устойчивость раскладки

Добавьте седьмую карточку с названием в две строки и увеличьте масштаб браузера до 150%. Исправьте места, где текст выходит за границы. Верните обычный масштаб. Покажите в готовом CSS три правила: одно управляет положением меню, второе — расстоянием между карточками, третье — переносом ряда. Объясните, что произойдёт при отключении каждого из них, и проверьте прогноз.
