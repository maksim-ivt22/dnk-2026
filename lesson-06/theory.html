Flexbox

Контейнер и его элементы

В расписании три занятия. Чтобы расположить их рядом, задайте display: flex общему родителю. Его непосредственные дочерние элементы станут участниками раскладки. Текст внутри каждой карточки сохранит обычный порядок.

<section class="schedule">
  <article>Математика</article>
  <article>История</article>
  <article>Информатика</article>
</section>

Две оси выравнивания

При обычном горизонтальном письме значение row направляет главную ось вдоль строки. justify-content распределяет свободное место вдоль этой оси, а align-items выравнивает карточки поперёк неё. Замените row на column и проследите, куда сместится группа.

.schedule {
  display: flex;
  flex-direction: row;
  justify-content: center;
  align-items: center;
  min-height: 10rem;
  gap: 1rem;
}

Перенос строк

Свойство gap задаёт расстояние между соседними элементами. Добавьте flex-wrap: wrap, чтобы при нехватке места следующая карточка начинала новый ряд. Значение flex-basis задаёт исходный размер карточки вдоль главной оси.

.schedule { flex-wrap: wrap; }
.schedule > article { flex-basis: 12rem; }

Как распределяется свободное место

Пусть внутренняя ширина расписания равна 640 px. Три карточки по 180 px и два промежутка по 20 px займут 580 px. Останется 60 px. При justify-content: center по краям ряда появится по 30 px. При space-between свободное место разделится между двумя промежутками: каждый увеличится с 20 до 50 px.

Когда карточке можно менять ширину

.schedule > article {
  flex: 1 1 180px;
}

Числа читаются по порядку. flex-grow: 1 позволяет карточке получить долю свободного места. flex-shrink: 1 разрешает уменьшить её при нехватке места. flex-basis: 180px задаёт начальный размер для расчёта. У одинаковых карточек в примере выше прибавка составит по 20 px. После роста свободного места для центрирования уже не останется.

Размеры в расчёте предполагают отсутствие внешних отступов и включают границы и padding карточек. Задайте карточкам box-sizing: border-box, как в предыдущем занятии.

Вопрос для самопроверки

Почему align-items: center иногда ничего не меняет на экране?

Если высота строки совпадает с высотой каждой карточки, свободного пространства для смещения нет. Задайте контейнеру min-height: 150px при одном ряде и сравните center с flex-start.
