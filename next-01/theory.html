Страницы и маршруты

Как адрес связан с файлом

В Next.js компонент React можно сделать страницей с помощью файловой маршрутизации App Router. Файл page.tsx описывает содержимое страницы, а имена вложенных папок определяют её адрес.

app/
  layout.tsx       // общая разметка
  page.tsx         // /
  courses/
    page.tsx       // /courses

Компонент страницы

Создайте в app/courses/page.tsx компонент со стандартным экспортом. При открытии /courses Next.js поместит результат этого компонента в общую разметку.

export default function Courses() {
  return <h1>Каталог курсов</h1>;
}

Общая навигация

Корневой layout.tsx содержит html и body. Параметр children получает содержимое текущей страницы. Внутри body перед children поместите навигацию, чтобы ссылки были доступны на обоих маршрутах. Для переходов внутри приложения используйте Link.

import Link from 'next/link';

// Навигация внутри компонента разметки
<nav aria-label="Основная навигация">
  <Link href="/">Главная</Link>{' · '}
  <Link href="/courses">Каталог</Link>
</nav>

Документация Next.js по установке и запуску

Проследите путь от адреса до экрана

  1. При открытии /courses система находит папку app/courses и её файл page.tsx.
  2. Компонент Courses возвращает заголовок каталога. Имя функции можно изменить: маршрут определяет положение файла.
  3. Корневая разметка получает содержимое страницы через children. На экране появляются меню из layout.tsx и заголовок из page.tsx.

Как выглядит корневая разметка целиком

import type { ReactNode } from 'react';
import Link from 'next/link';

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="ru">
      <body>
        <nav aria-label="Основная навигация">
          <Link href="/">Главная</Link>{' · '}
          <Link href="/courses">Каталог</Link>
        </nav>
        {children}
      </body>
    </html>
  );
}

Тип ReactNode позволяет передать в children содержимое страницы. Если убрать {children}, навигация останется на экране, но заголовок маршрута исчезнет. В созданном проекте сохраните импорт глобальных стилей при редактировании разметки.

Предскажите адрес

Какой файл создаст страницу /courses/design?

app/courses/design/page.tsx. Папки courses и design образуют сегменты адреса. Файл app/courses/design.tsx сам по себе страницу по этому адресу не создаёт.
