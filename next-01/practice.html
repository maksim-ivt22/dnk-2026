Страницы и маршруты

Задача

Создайте сайт школьных кружков. На главной странице разместите название сайта, в каталоге — список кружков. Добавьте общее меню для перехода между страницами.

1. Подготовьте компьютер

Для работы нужны браузер, редактор кода, например Visual Studio Code, и доступ в интернет для установки библиотек.

  1. В Windows откройте «Пуск», введите cmd и запустите «Командную строку». Терминал принимает текстовые команды. Вводите по одной строке и нажимайте Enter.
  2. Введите node -v, затем npm -v. Node.js запускает JavaScript на компьютере, а npm устанавливает библиотеки. На экране должны появиться два номера версий. Для проекта нужен Node.js версии 20.9 или выше.
  3. Если команда не найдена или Node.js устарел, откройте страницу загрузки Node.js. На личном компьютере установите LTS-версию для вашей системы со стандартными параметрами. В классе, если нужны права администратора, обратитесь к преподавателю. Закройте терминал, откройте новый и повторите проверку.
  4. Создайте в Проводнике папку web-school для учебных проектов. Откройте её, щёлкните адресную строку, введите cmd и нажмите Enter. В открывшемся окне путь перед знаком > должен оканчиваться на web-school.

2. Создайте приложение с помощью мастера

npx create-next-app@latest school-site --use-npm

npx запускает мастер, а school-site задаёт имя новой папки. Если появится запрос на установку create-next-app, введите y. Выберите ручную настройку (Customize). Выбор меняется стрелками и подтверждается клавишей Enter.

  • TypeScript — Yes. В примерах используются файлы .tsx, в которых можно писать разметку компонента.
  • App Router — Yes. Этот вариант связывает адреса страниц с папками внутри app.
  • Папка src — No. Тогда файл главной страницы будет лежать в app/page.tsx.
  • Выберите ESLint для проверки кода. Tailwind CSS для урока можно отключить. Для остальных вопросов оставьте предложенные значения.

Дождитесь окончания установки. Откройте в редакторе «Файл → Открыть папку» и выберите school-site внутри web-school. Найдите package.json со списком библиотек и команд, app со страницами и node_modules, куда npm установил библиотеки.

3. Запустите сервер и проверьте первую правку

В том же терминале, где работал мастер, выполните по очереди:

cd school-site
npm run dev

cd переводит терминал в папку проекта. Команда npm run dev запускает сервер разработки. Оставьте окно открытым и введите в браузере адрес из строки Local, обычно http://localhost:3000. Имя localhost означает ваш компьютер, число — порт, на котором работает сервер.

Найдите в app/page.tsx фразу со стартового экрана. Замените её названием школы и нажмите Ctrl+S. Текст в браузере должен измениться. Если npm сообщает об отсутствии package.json, введите dir и проверьте, что терминал открыт в папке school-site.

4. Создайте две страницы

Замените компонент в app/page.tsx приведённым ниже. Затем создайте app/courses/page.tsx по примеру из теории и добавьте под заголовком список из трёх курсов. Оберните заголовок и список в элемент main.

export default function Home() {
  return <h1>Учебный центр</h1>;
}

5. Свяжите маршруты

В app/layout.tsx добавьте импорт Link в начале файла и блок nav из теории перед {children}. Установите lang="ru" у html. Откройте каталог по ссылке, обновите страницу и вернитесь на главную через меню. Сверьте заголовок каждой страницы с адресом в браузере.

6. Наполните каталог

Замените содержимое app/courses/page.tsx этим компонентом. Добавьте четвёртый курс в массив и проверьте, как изменится страница после сохранения файла.

const courses = ['Основы HTML', 'Вёрстка с CSS', 'Компоненты React'];

export default function Courses() {
  return (
    <main>
      <h1>Каталог курсов</h1>
      <ul>
        {courses.map(course => <li key={course}>{course}</li>)}
      </ul>
    </main>
  );
}

В этом списке названия уникальны и служат ключами элементов. Навигация располагается в layout.tsx, поэтому изменение списка не требует правок в меню.

7. Если результат отличается

  • При ответе 404 для /courses проверьте имя page.tsx и расположение папки courses внутри app. Если при установке выбрана папка src, рабочий путь начинается с src/app.
  • Если браузер сообщает о недоступном сайте, проверьте, продолжает ли работать npm run dev, и откройте адрес с портом из терминала.
  • Если при переходе меняется адрес, но видна только навигация, проверьте вывод {children} в корневой разметке.

8. Проверка маршрутов и повторный запуск

Откройте каталог в новой вкладке и перейдите на главную страницу через меню. Затем добавьте лишнюю букву в адрес /courses. Объясните ошибку 404 по дереву файлов и восстановите правильный адрес.

В терминале остановите сервер сочетанием Ctrl+C. Снова выполните npm run dev в папке с package.json и откройте каталог. Для сдачи запишите его адрес, путь к файлу страницы и имя файла с общим меню.

9. Разработайте раздел мероприятий

На сайте кружков нужен раздел с ближайшими встречами. Посетитель должен открыть список, выбрать встречу и узнать, когда она начнётся и что взять с собой. Сделайте этот раздел самостоятельно, используя работающий каталог как образец.

  1. На бумаге сопоставьте адреса /events, /events/open-day и /events/workshop с файлами проекта. Затем создайте папки и страницы. Сначала выведите на каждой странице только её заголовок и проверьте все три адреса напрямую.
  2. Для дня открытых дверей и мастер-класса придумайте дату, место и условия участия. На страницах встреч добавьте по одному абзацу описания и ссылку возврата к списку.
  3. Добавьте «Мероприятия» в общую навигацию. Проверьте ссылку с главной страницы, из каталога и с любой страницы встречи.

10. Отделите данные от разметки

Карточки встреч отличаются содержимым, но устроены одинаково. Создайте файл app/events/events.ts. Опишите в нём массив объектов по приведённому образцу и самостоятельно добавьте вторую встречу.

export const events = [
  {
    slug: 'open-day',
    title: 'День открытых дверей',
    place: 'Мастерская',
    date: '15 сентября',
  },
];

В app/events/page.tsx импортируйте массив через import { events } from './events';. Преобразуйте записи в список с помощью map. Используйте slug как key. Для ссылки соберите адрес из общей части /events/ и значения slug. Проверьте соответствие имени папки и значения slug у обеих встреч.

Как собрать адрес из двух частей?
<Link href={'/events/' + event.slug}>{event.title}</Link>

Здесь event — текущая запись внутри map. Импортируйте Link из next/link в файле, который его использует.

11. Выделите компонент карточки

Создайте app/events/EventCard.tsx. Перенесите в компонент разметку одной карточки и передайте ей данные встречи через props. Для TypeScript опишите поля объекта. Используйте эту заготовку сигнатуры:

type EventInfo = {
  slug: string;
  title: string;
  place: string;
  date: string;
};

export default function EventCard({ event }: { event: EventInfo }) {
  // Верните карточку с названием-ссылкой, датой и местом.
}

Импортируйте EventCard в страницу списка. Внутри map передайте текущую запись в компонент. Если список размечен через ul, непосредственным дочерним элементом должен быть li. Поставьте key на внешний элемент, который возвращает map.

Добавьте третью встречу «Выставка проектов» и страницу с её описанием. Проверьте, что для появления ещё одной карточки в списке достаточно добавить запись в массив. Измените место проведения и убедитесь, что список показывает новое значение.

12. Найдите и исправьте ошибку маршрутизации

Временно измените slug одной встречи только в массиве. Откройте карточку из списка. Запишите полученный URL, найдите на диске соответствующую папку и объясните ответ 404. Восстановите совпадение адресов. Теперь откройте правильный адрес в новой вкладке и обновите страницу.

13. Проверьте готовый проект

  1. Начните с главной страницы. Откройте мероприятия, выберите каждую встречу по очереди и вернитесь к списку по ссылке. У всех встреч должны быть разные адреса и описания.
  2. Остановите сервер разработки через Ctrl+C. В папке с package.json выполните npm run build. Если сборка остановится, прочитайте первое сообщение с именем вашего файла, исправьте ошибку и запустите команду снова.
  3. После успешной сборки выполните npm start. Откройте адрес из терминала и проверьте прямой переход на страницу выставки. Завершите сервер через Ctrl+C.

По готовому проекту объясните, где добавить встречу, где изменить внешний вид всех карточек и какой файл отвечает за адрес отдельной страницы.
