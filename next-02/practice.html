Улучшаем сайт учебного центра

Работайте в проекте school-site из первого занятия Next.js. Используются TypeScript, App Router и папка app в корне проекта. Если в вашем проекте выбрана папка src, создавайте папки app, components и lib внутри src, сохраняя показанные относительные импорты.

1. Запустите существующий проект

  1. Откройте папку проекта в редакторе. В терминале перейдите в неё: рядом должен находиться package.json.
  2. Выполните npm run dev. Откройте адрес из строки Local и проверьте главную страницу и /courses.
  3. Найдите текущее меню в app/layout.tsx и заголовок каталога в app/courses/page.tsx. Если проекта нет, сначала выполните шаги создания проекта и двух страниц из первого занятия.

Для сохранности своей работы можно сделать копию проекта до изменений. Рабочий сервер разработки оставьте запущенным.

school-site/
  app/
    layout.tsx
    page.tsx
    courses/
      layout.tsx          // создадим
      page.tsx
      courses.module.css  // создадим
      web/page.tsx        // проверочная страница, если её ещё нет
  components/             // создадим
    SiteHeader.tsx
    SiteFooter.tsx
    SiteChrome.module.css
    CourseCard.tsx
    CourseCard.module.css
  lib/
    courses.ts            // создадим

2. Вынесите шапку в компонент

Создайте папку components рядом с app и файл components/SiteHeader.tsx. Если в старом меню есть ссылки на другие уже созданные страницы, добавьте их в новое меню.

import Link from 'next/link';
import styles from './SiteChrome.module.css';

export default function SiteHeader() {
  return (
    <header className={styles.header}>
      <Link className={styles.brand} href="/">Учебный центр</Link>
      <nav className={styles.nav} aria-label="Основная навигация">
        <Link href="/">Главная</Link>
        <Link href="/courses">Каталог</Link>
      </nav>
    </header>
  );
}

3. Добавьте подвал и стили

Создайте components/SiteFooter.tsx:

import styles from './SiteChrome.module.css';

export default function SiteFooter() {
  return (
    <footer className={styles.footer}>
      <p>Учебный центр · Вопросы о курсах задавайте преподавателю.</p>
    </footer>
  );
}

Создайте общий для этих двух компонентов CSS-модуль components/SiteChrome.module.css:

.header {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  justify-content: space-between;
  gap: 16px;
  padding: 20px;
  background: #0f172a;
}
.header a { color: white; }
.brand { font-weight: bold; }
.nav { display: flex; flex-wrap: wrap; gap: 16px; }
.footer { margin-top: 32px; padding: 20px; background: #e2e8f0; color: #0f172a; }

4. Подключите компоненты к корневому layout

В начале app/layout.tsx добавьте импорты:

import SiteHeader from '../components/SiteHeader';
import SiteFooter from '../components/SiteFooter';

Внутри существующего body замените старый блок навигации на <SiteHeader />, а после {children} добавьте <SiteFooter />. Не создавайте второй body и не удаляйте его существующие атрибуты. Сохраните html, children, импорт globals.css, метаданные и другие настройки проекта. Если старый импорт Link больше нигде в этом файле не используется, удалите его.

{/* Порядок содержимого внутри существующего body: */}
<SiteHeader />
{children}
<SiteFooter />

Откройте / и /courses. На обеих страницах должны быть одна шапка, одна навигация и один подвал. Перейдите по обеим ссылкам. Если видите две навигации, проверьте, удалён ли старый блок из layout.

5. Создайте layout раздела курсов

Создайте app/courses/layout.tsx:

import type { ReactNode } from 'react';
import styles from './courses.module.css';

export default function CoursesLayout({ children }: { children: ReactNode }) {
  return (
    <div className={styles.section}>
      <p className={styles.note}>Раздел курсов учебного центра</p>
      {children}
    </div>
  );
}

Создайте app/courses/courses.module.css. Позже в этот же файл добавим стиль сетки.

.section { max-width: 1100px; margin: 0 auto; padding: 24px 16px; }
.note { padding: 12px; background: #dbeafe; color: #1e3a8a; border-radius: 8px; }

Откройте /courses: над содержимым появилась подпись раздела. На главной её быть не должно. Чтобы проверить вложенную страницу, откройте /courses/web. Если она уже есть после первого занятия, сохраните её; если её нет, создайте app/courses/web/page.tsx:

export default function WebCourse() {
  return <main><h1>Основы HTML</h1><p>Создаём первую веб-страницу.</p></main>;
}

При прямом открытии и обновлении /courses/web должны отображаться шапка, подпись раздела, содержимое курса и подвал. Объясните, какой из двух layout добавил каждый общий элемент.

6. Отделите данные курсов

Создайте папку lib рядом с app и файл lib/courses.ts. Тип описывает поля каждой записи; id будет уникальным ключом карточки.

export type Course = {
  id: string;
  title: string;
  description: string;
  duration: string;
};

export const courses: Course[] = [
  { id: 'html', title: 'Основы HTML', description: 'Создаём структуру страницы.', duration: '4 занятия' },
  { id: 'css', title: 'Вёрстка с CSS', description: 'Оформляем и размещаем блоки.', duration: '6 занятий' },
  { id: 'react', title: 'Компоненты React', description: 'Собираем интерфейс из компонентов.', duration: '4 занятия' },
];

Добавьте четвёртый курс со своим уникальным id. В этом упражнении данные находятся в файле, поэтому сервер API и база данных не требуются.

7. Сделайте компонент карточки

Создайте components/CourseCard.tsx. Он получает один объект типа Course через props и показывает все поля, кроме служебного id.

import type { Course } from '../lib/courses';
import styles from './CourseCard.module.css';

export default function CourseCard({ course }: { course: Course }) {
  return (
    <article className={styles.card}>
      <h2>{course.title}</h2>
      <p>{course.description}</p>
      <p>Продолжительность: {course.duration}</p>
    </article>
  );
}

Создайте components/CourseCard.module.css:

.card {
  min-width: 0;
  padding: 20px;
  border: 1px solid #cbd5e1;
  border-radius: 12px;
  background: #f8fafc;
  color: #1e293b;
  overflow-wrap: anywhere;
}
.card h2 { margin-top: 0; }

8. Соберите каталог из карточек

Замените содержимое app/courses/page.tsx следующим кодом. Если на странице есть ваша собственная важная информация, сохраните её внутри main после заголовка.

import CourseCard from '../../components/CourseCard';
import { courses } from '../../lib/courses';
import styles from './courses.module.css';

export default function Courses() {
  return (
    <main>
      <h1>Каталог курсов</h1>
      <div className={styles.grid}>
        {courses.map((course) => (
          <CourseCard key={course.id} course={course} />
        ))}
      </div>
    </main>
  );
}

В конец app/courses/courses.module.css добавьте сетку:

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 15rem), 1fr));
  gap: 16px;
}

В каталоге должно появиться четыре карточки. Поменяйте описание одного курса в lib/courses.ts и убедитесь, что изменилось содержимое нужной карточки. Измените рамку в CSS-модуле карточки — оформление изменится у всех карточек.

9. Самостоятельно примените компонент

  1. Добавьте на главную страницу блок «Рекомендуемый курс». Импортируйте CourseCard из ../components/CourseCard и массив courses из ../lib/courses. Передайте в карточку courses[0]. Сохраните существующее содержимое главной страницы.
  2. Измените название первого курса в массиве. Проверьте, что оно изменилось и на главной, и в каталоге.
  3. Добавьте в подвал название вашей школы. Проверьте его на главной, в каталоге и на странице курса.

Если проект использует строгую проверку доступа к элементам массива и редактор сообщает, что courses[0] может отсутствовать, сначала проверьте его: {courses[0] && <CourseCard course={courses[0]} />}.

10. Проверьте и покажите результат

  1. Откройте напрямую /, /courses и /courses/web, обновите каждую страницу и проверьте переходы меню. Подпись раздела должна появляться только на двух адресах с /courses.
  2. Проверьте каталог при ширине 375 и 1200 px: карточки должны перестраиваться без горизонтальной прокрутки.
  3. Остановите сервер клавишами Ctrl+C. В папке с package.json выполните npm run build. Если сборка сообщает об ошибке, прочитайте путь и первое сообщение, исправьте файл и повторите сборку. После успешной сборки можно запустить npm start и проверить страницы ещё раз; завершите сервер через Ctrl+C.

Покажите дерево файлов и объясните, где изменить общую навигацию, подпись раздела, данные одного курса и внешний вид всех карточек.

Если что-то не работает
  • Module not found: сверьте имена папок, регистр букв и относительный путь импорта. При использовании src все три папки должны находиться внутри src.
  • Виден только текст layout: проверьте {children} в корневом и вложенном layout.
  • Стили карточки отсутствуют: файл должен называться CourseCard.module.css; проверьте импорт и className={styles.card}.
  • Карточка не появилась: сохраните файл данных, проверьте запятые в массиве и уникальность каждого id.
