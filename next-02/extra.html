Кнопка избранного

Задача

После основной работы добавьте в каждую карточку кнопку избранного. По нажатию она меняет состояние и текст. Для каждой карточки состояние должно быть независимым. Это задание выполняется дополнительно к трёхчасовому занятию.

1. Создайте интерактивный компонент

Создайте components/FavoriteButton.tsx. Директива в первой строке объявляет клиентский компонент, который может использовать состояние и обработчик нажатия.

'use client';

import { useState } from 'react';

export default function FavoriteButton({ title }: { title: string }) {
  const [favorite, setFavorite] = useState(false);

  return (
    <button
      type="button"
      aria-label={'Избранное: ' + title}
      aria-pressed={favorite}
      onClick={() => setFavorite(!favorite)}
    >
      {favorite ? 'В избранном' : 'В избранное'}
    </button>
  );
}

aria-pressed сообщает вспомогательным технологиям состояние кнопки. Состояние хранится в памяти компонента и после обновления страницы сбросится; постоянное хранение здесь не предусмотрено.

2. Подключите кнопку к карточке

В components/CourseCard.tsx добавьте импорт import FavoriteButton from './FavoriteButton';. Внутри article после описания курса разместите <FavoriteButton title={course.title} />. Карточку, страницу и layout менять на клиентские компоненты не нужно.

Добавьте собственные стили кнопки. Проверьте видимый фокус клавиатуры и читаемость текста.

3. Проверьте

  1. Нажмите кнопку одной карточки, затем другой. Убедитесь, что состояние первой не изменилось.
  2. Найдите кнопку клавишей Tab и переключите её клавишей Enter или пробелом.
  3. Обновите страницу и объясните, почему отметки исчезли. Выполните npm run build после остановки сервера разработки.

Объясните, в каком файле находится директива 'use client' и почему она нужна кнопке. Справка: Server и Client Components.
