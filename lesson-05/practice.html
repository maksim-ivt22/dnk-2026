Практическая работа №5

Создаём карточки мероприятий с помощью CSS Box Model

Задача

Создай страницу «Афиша мероприятий».

На странице должны быть три разные карточки мероприятий.

Каждая карточка должна содержать:
  • название мероприятия;
  • дату;
  • место проведения;
  • небольшое описание;
  • ссылку «Подробнее».
В CSS обязательно используй:
  • width;
  • padding;
  • margin;
  • border;
  • border-radius;
  • box-sizing.

1. Создай первую карточку

<div class="event-card">

    <h2>
        День открытых дверей
    </h2>

    <p class="date">
        15 ноября
    </p>

    <p>
        Актовый зал
    </p>

    <p>
        Знакомство с направлениями,
        преподавателями и проектами.
    </p>

    <a href="#">
        Подробнее
    </a>

</div>

2. Создай три карточки

Темы придумай самостоятельно.

Например: 

День открытых дверей

Мастер-класс по робототехнике

Школьный фестиваль проектов
Не обязательно использовать эти варианты. Можно придумать свои мероприятия.

3. Добавь box-sizing

* {
    box-sizing: border-box;
}

4. Ограничь ширину страницы

.events {
    max-width: 900px;
    margin: 0 auto;
}

HTML: 

<main class="events">

    ...

</main>

5. Задай ширину карточки

.event-card {
    width: 400px;
}

Попробуй затем: 

width: 320px;

Сравни результат.

6. Добавь внутренний отступ

.event-card {
    width: 400px;
    padding: 24px;
}
Сначала поставь padding: 5px;. Потом padding: 30px;. Сравни внешний вид.

7. Добавь рамку

.event-card {
    width: 400px;
    padding: 24px;

    border: 1px solid #cbd5e1;
}

8. Скругли углы

.event-card {
    border-radius: 16px;
}

9. Добавь расстояние между карточками

.event-card {
    margin-bottom: 25px;
}

10. Добавь фон

.event-card {
    background: white;
}

11. Выдели дату

HTML: 

<p class="date">
    15 ноября
</p>

CSS: 

.date {
    color: #2563eb;
    font-weight: bold;
}

12. Оформи ссылку

.event-card a {
    color: #2563eb;
    text-decoration: none;
}

13. Сделай одну карточку особенной

Добавь второй класс: 

<div class="event-card important-event">

CSS: 

.important-event {
    border: 3px solid #2563eb;
}

14. Эксперимент с margin

Попробуй: 

margin-bottom: 5px;

Затем: 

margin-bottom: 50px;

Оставь подходящее значение.

15. Эксперимент с border

border: 2px solid #334155;
border: 2px dashed #334155;
border: 2px dotted #334155;

Выбери вариант, который подходит дизайну.

16. Итоговый пример CSS

* {
    box-sizing: border-box;
}

body {
    margin: 0;
    background: #f1f5f9;
    font-family: Arial, sans-serif;
}

.events {
    max-width: 900px;
    margin: 0 auto;
}

.event-card {
    width: 400px;

    padding: 24px;
    margin-bottom: 25px;

    background: white;

    border: 1px solid #cbd5e1;
    border-radius: 16px;
}

.date {
    color: #2563eb;
    font-weight: bold;
}

.event-card a {
    color: #2563eb;
    text-decoration: none;
}

.important-event {
    border: 3px solid #2563eb;
}
Не оставляй пример без изменений.

Самостоятельно измени минимум:

  • цвет страницы;
  • ширину карточек;
  • padding;
  • border;
  • border-radius.

17. Проверь через DevTools

Выбери одну карточку через инструменты разработчика.

Найди схему: 

margin
border
padding
content

Проверка

Есть три разных мероприятия

Используется box-sizing

Есть width

Есть padding

Есть margin

Есть border

Есть border-radius

Одна карточка выделяется

Есть отдельный класс для даты

Использован общий контейнер

Box Model проверен через DevTools

Дизайн изменён самостоятельно

Готово?

Покажи преподавателю одну карточку через DevTools.

Объясни разницу между:

  • padding;
  • border;
  • margin.
