Занятие №5 — CSS Box Model

Margin, padding, border, width и карточки

CSS Box Model
Цель занятия: понять, из чего состоит каждый HTML-элемент и научиться управлять его размером, внутренними и внешними отступами.

1. Что такое Box Model?

Браузер рассматривает каждый HTML-элемент как прямоугольную коробку.

У этой коробки есть несколько слоёв.

margin
└── border
....└── padding
.......└── content

То есть:

  • content — содержимое;
  • padding — внутренний отступ;
  • border — рамка;
  • margin — внешний отступ.

2. Content

Content — содержимое элемента.

Например: 

<div>
    Clash Royale
</div>

Текст Clash Royale — это content.

3. Width

width задаёт ширину элемента. 

.card {
    width: 300px;
}

4. Height

height задаёт высоту. 

.card {
    height: 200px;
}
Высоту карточек не всегда нужно задавать вручную. Часто лучше позволить содержимому определить высоту автоматически.

5. Padding

padding — расстояние между содержимым и границей элемента. 

.card {
    padding: 20px;
}
border | | padding | | | | TEXT | | |

Чем больше padding, тем больше воздуха внутри элемента.

6. Padding по сторонам

.card {
    padding-top: 20px;
    padding-right: 30px;
    padding-bottom: 20px;
    padding-left: 30px;
}

7. Короткая запись padding

.card {
    padding: 20px 30px;
}

Здесь: 

20px → сверху и снизу
30px → слева и справа

8. Border

border создаёт рамку. 

.card {
    border: 2px solid black;
}

Здесь:

  • 2px — толщина;
  • solid — тип линии;
  • black — цвет.

9. Другие виды border

border: 2px solid black;

border: 2px dashed blue;

border: 2px dotted red;

10. Border-radius

Мы уже встречали: 

border-radius: 16px;

Это скругляет углы коробки.

11. Margin

margin — внешний отступ между элементами. 

.card {
    margin: 20px;
}
CARD 1 margin CARD 2

12. Margin по сторонам

.card {
    margin-top: 20px;
    margin-right: 10px;
    margin-bottom: 20px;
    margin-left: 10px;
}

13. Центрирование блока

Очень полезная запись: 

.container {
    width: 800px;
    margin: 0 auto;
}

auto слева и справа помогает разместить блок по центру.

14. В чём разница margin и padding?

padding ↓
пространство ВНУТРИ элемента
margin ↓
пространство СНАРУЖИ элемента
Если текст слишком близко к рамке — нужен padding.

Если два блока слишком близко друг к другу — нужен margin.

15. Пример карточки

HTML: 

<div class="card">

    <h2>
        Elden Ring
    </h2>

    <p>
        Action RPG
    </p>

</div>

CSS: 

.card {
    width: 300px;
    padding: 20px;
    margin: 20px;
    border: 2px solid #cbd5e1;
    border-radius: 16px;
}

16. Проблема с width

Допустим: 

.card {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
}

Без дополнительных настроек реальный размер может оказаться больше 300px.

17. box-sizing

Поэтому часто используют: 

* {
    box-sizing: border-box;
}

Тогда width включает padding и border.

В наших проектах удобно сразу писать:

* { box-sizing: border-box; }

18. Без border-box

width: 300px + padding + border = реальный размер больше 300px

19. С border-box

width: 300px
↓
content + padding + border
↓
всё помещается в 300px

20. max-width

Часто полезнее использовать: 

.container {
    max-width: 1000px;
}

Это означает: элемент может быть меньше, но не шире 1000px.

21. width: 100%

img {
    width: 100%;
}

Изображение займёт всю доступную ширину родителя.

22. Карточка с изображением

<div class="card">

    <img src="game.jpg" alt="Elden Ring">

    <h2>
        Elden Ring
    </h2>

    <p>
        Action RPG
    </p>

</div>

CSS: 

.card {
    width: 300px;
    padding: 20px;
    border: 1px solid #cbd5e1;
    border-radius: 16px;
    margin-bottom: 20px;
}

.card img {
    width: 100%;
    border-radius: 10px;
}

23. Почему .card img?

Запись: 

.card img

означает:

выбрать изображения, которые находятся внутри элемента с классом card.

24. Пример layout без Flexbox

<main class="container">

    <div class="card">
        ...
    </div>

    <div class="card">
        ...
    </div>

</main>

CSS: 

.container {
    max-width: 900px;
    margin: 0 auto;
}

.card {
    margin-bottom: 20px;
}

25. Частая ошибка

.card {
    margin: 50px;
    padding: 50px;
}

Слишком большие отступы могут сделать страницу неудобной.

Не ставь случайные огромные значения. Меняй отступы постепенно и смотри на результат.
