CSS Box Model — Extra

Создаём страницу профиля и информационные блоки

Задача

Создай небольшую страницу профиля участника кружка.

На этот раз не делаем набор одинаковых карточек.

На странице должны появиться:
  1. главный профильный блок;
  2. блок «О себе»;
  3. блок «Навыки»;
  4. информационное сообщение;
  5. кнопка-ссылка.

1. Создай профильный блок

<section class="profile">

    <img src="avatar.jpg" alt="Фото участника">

    <h1>
        Максим Иванов
    </h1>

    <p>
        Ученик 10 класса
    </p>

    <p>
        Изучаю веб-разработку.
    </p>

</section>

2. Оформи профиль

.profile {
    width: 500px;

    margin: 30px auto;
    padding: 30px;

    border: 1px solid #cbd5e1;
    border-radius: 20px;

    background: white;
}

3. Оформи изображение

.profile img {
    width: 150px;
    height: 150px;

    border-radius: 50%;
}
Значение border-radius: 50% превращает квадратное изображение в круг.

4. Добавь блок «О себе»

<section class="info-block">

    <h2>
        О себе
    </h2>

    <p>
        Мне нравится создавать сайты
        и изучать новые технологии.
    </p>

</section>

5. Оформи info-block

.info-block {
    max-width: 700px;

    margin: 20px auto;
    padding: 25px;

    border-left: 5px solid #2563eb;

    background: white;
}

6. Добавь блок «Навыки»

<section class="info-block">

    <h2>
        Навыки
    </h2>

    <ul>

        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>

    </ul>

</section>

7. Сделай информационное сообщение

<div class="notice">

    Сейчас изучаю CSS Box Model.

</div>

CSS: 

.notice {
    max-width: 700px;

    margin: 20px auto;
    padding: 20px;

    border: 2px solid #2563eb;
    border-radius: 12px;

    background: #eff6ff;
}

8. Добавь кнопку-ссылку

<a
    class="button"
    href="#"
>
    Посмотреть мои работы
</a>

CSS: 

.button {
    display: inline-block;

    padding: 12px 20px;
    margin-top: 15px;

    border: 2px solid #2563eb;
    border-radius: 10px;

    color: #2563eb;

    text-decoration: none;
}

9. Эксперимент с padding

Для блока profile попробуй: 

padding: 5px;

Потом: 

padding: 50px;

Сравни результат.

10. Эксперимент с margin

Для info-block попробуй: 

margin: 5px auto;

Затем: 

margin: 60px auto;

11. Сделай разные информационные блоки

Добавь: 

<div class="message success">
    Работа сохранена
</div>

<div class="message warning">
    Осталось закончить проект
</div>

Общий CSS: 

.message {
    max-width: 700px;

    margin: 15px auto;
    padding: 18px;

    border-radius: 10px;
}

Отдельные стили придумай самостоятельно: 

.success {

}

.warning {

}

12. Используй border с одной стороны

Например: 

.success {
    border-left: 6px solid green;
}

Для warning подбери свой цвет.

13. Проверь box-sizing

Временно убери: 

* {
    box-sizing: border-box;
}

Для profile установи: 

width: 500px;
padding: 50px;
border: 10px solid black;

Посмотри ширину через DevTools.

Затем верни: 

* {
    box-sizing: border-box;
}
Объясни преподавателю, почему размер изменился.

14. Самостоятельная часть

Добавь ещё один смысловой блок.

Например:

  • «Мои цели»;
  • «Мои проекты»;
  • «Контакты»;
  • «Что хочу изучить».

Но HTML и CSS напиши самостоятельно.

Проверка

Есть главный профильный блок

Использован width

Использован max-width

Использован padding

Использован margin

Использован border

Использован border-left

Использован border-radius

Есть круглая картинка

Есть кнопка-ссылка

Есть минимум два информационных сообщения

Проведён эксперимент с box-sizing

Добавлен самостоятельный блок

HARD — max-width

Сделай основной блок: 

.profile {
    width: 100%;
    max-width: 600px;
}

Изменяй ширину браузера и наблюдай за поведением блока.

Объясни разницу между: 

width: 600px;

и: 

width: 100%;
max-width: 600px;

SUPER HARD — min-height

Создай два блока с разным количеством текста.

Добавь: 

min-height: 180px;

Затем сравни с: 

height: 180px;

Объясни разницу.

ULTRA — overflow

Создай блок: 

.bio {
    width: 300px;
    height: 100px;
}

Добавь много текста.

Затем проверь: 

overflow: hidden;

overflow: auto;

overflow: scroll;

Объясни, чем отличаются эти значения.

Итог

После Extra ты применил Box Model уже не к игровым карточкам, а к полноценному интерфейсу:

  • профиль;
  • информационные блоки;
  • уведомления;
  • кнопка;
  • контентные секции.
