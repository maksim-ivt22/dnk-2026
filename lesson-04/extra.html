```html Дополнительное задание №4 — CSS

Дополнительное задание №4

Делаем собственную тему оформления сайта

Задача

Сделай сайт визуально похожим на настоящий игровой сайт.

Теперь готового решения будет меньше.

Нужно самостоятельно оформить:
  1. всю страницу;
  2. шапку;
  3. меню;
  4. разделы;
  5. картинки;
  6. ссылки.

1. Создай тему

Выбери один вариант:

  • тёмная тема;
  • синяя тема;
  • красно-чёрная тема;
  • зелёная тема;
  • игровая тема;
  • или придумай свою.

2. Оформи body

Например для тёмной темы: 

body {
    background: #111827;
    color: white;
    font-family: Arial, sans-serif;
}
Это только пример. Можно выбрать свои цвета.

3. Оформи header

В HTML уже есть: 

<header>

    <h1>
        Games
    </h1>

</header>

Попробуй: 

header {
    background: #2563eb;
    color: white;
    text-align: center;
}

4. Оформи nav

nav {
    background: #1e293b;
    text-align: center;
}

nav a {
    color: white;
}

5. Наведение мыши

Новый селектор: 

nav a:hover {
    color: yellow;
}
:hover применяется, когда пользователь наводит мышь на элемент.

6. Добавь hover для картинки

img:hover {
    border-radius: 50px;
}

Посмотри, что произойдёт.

7. Добавь фон для section

section {
    background: white;
}

Если сайт тёмный, можно использовать: 

section {
    background: #1e293b;
}

8. Создай уникальные классы

Например: 

<p class="rating">
    10/10
</p>
.rating {
    color: #f59e0b;
    font-size: 24px;
}

9. Добавь класс danger

HTML: 

<p class="danger">
    Очень сложная игра
</p>

CSS придумай самостоятельно.

10. Сделай разные ссылки

Обычная ссылка: 

a {
    color: #2563eb;
}

При наведении: 

a:hover {
    color: #7c3aed;
}

11. Поэкспериментируй с border-radius

border-radius: 0;

border-radius: 10px;

border-radius: 30px;

border-radius: 50%;
Попробуй каждое значение и выбери лучшее.

12. Добавь новый CSS-класс самостоятельно

Придумай класс: 

.best-game {

}

И оформи с его помощью свою любимую игру.

Проверка

☐ Создана собственная цветовая тема

☐ Оформлен body

☐ Оформлен header

☐ Оформлен nav

☐ Оформлены ссылки

☐ Использован :hover

☐ Есть минимум 3 CSS-класса

☐ Используется border-radius

☐ Изображения имеют собственный стиль

☐ Дизайн отличается от примеров преподавателя

HARD

Самостоятельно узнай, что делает: 

border

И попробуй: 

border: 3px solid #2563eb;

Добавь рамку к картинке или разделу.

SUPER HARD

Самостоятельно узнай, что делает: 

box-shadow

Попробуй: 

box-shadow:
    0 10px 30px rgba(0,0,0,0.2);

Используй тень минимум для одного элемента сайта.

ULTRA

Найди самостоятельно, что такое: 

transition

Попробуй сделать, чтобы изменение цвета при :hover происходило плавно.

Подсказка: 

transition: 0.3s;

Итог

После Extra ты уже используешь:

  • селекторы тегов;
  • CSS-классы;
  • цвета;
  • фон;
  • шрифты;
  • размеры;
  • border-radius;
  • :hover;
  • border;
  • box-shadow;
  • transition.
```
