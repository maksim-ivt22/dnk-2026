Занятие №4 — Первые стили CSS

Цвета, фон, шрифты и подключение CSS

CSS Стили 3 часа
Цель занятия: научиться изменять внешний вид HTML-страницы с помощью CSS.

1. Что такое CSS?

CSS отвечает за внешний вид сайта.

HTML ↓ Что находится на странице
CSS ↓ Как страница выглядит

Например, HTML: 

<h1>Мой сайт</h1>

CSS: 

h1 {
    color: blue;
}

Теперь заголовок станет синим.

2. Как подключить CSS?

Есть несколько способов. Пока изучим два.

Способ 1 — внутри HTML

<head>

    <style>

        h1 {
            color: blue;
        }

    </style>

</head>

Способ 2 — отдельный файл

Создаём: 

style.css

И подключаем: 

<link rel="stylesheet" href="style.css">
На настоящих сайтах обычно удобнее использовать отдельный CSS-файл.

3. Структура CSS

h1 {
    color: blue;
}

Здесь:

  • h1 — что выбираем;
  • color — что меняем;
  • blue — новое значение.
selector { property: value; }

4. Селектор по тегу

p {
    color: green;
}

Все теги <p> станут зелёными.

5. Цвет текста

h1 {
    color: red;
}

Можно использовать: 

red
blue
green
orange
purple
black

Или HEX: 

color: #2563eb;

6. Цвет фона

body {
    background: lightblue;
}

Или: 

body {
    background: #f1f5f9;
}

7. Размер текста

h1 {
    font-size: 40px;
}
p {
    font-size: 18px;
}
px — пиксели.

8. Шрифт

body {
    font-family: Arial, sans-serif;
}

Можно использовать: 

Arial
Verdana
Georgia
Tahoma
Courier New

9. Выравнивание текста

h1 {
    text-align: center;
}

Возможные значения: 

left
center
right

10. Ширина

img {
    width: 300px;
}

Теперь все изображения будут шириной 300px.

11. Высота

img {
    width: 300px;
    height: 200px;
}
С изображениями высоту пока лучше менять осторожно: картинка может растянуться.

12. Скругление

img {
    border-radius: 20px;
}

Чем больше значение, тем сильнее скругление.

13. CSS-классы

Иногда мы не хотим менять абсолютно все элементы одного типа.

Для этого есть class.

HTML: 

<p class="important-text">
    Очень важный текст
</p>

CSS: 

.important-text {
    color: red;
}
Перед названием класса в CSS ставится точка: .

14. Один класс можно использовать много раз

<p class="game">
    Elden Ring
</p>

<p class="game">
    Minecraft
</p>

<p class="game">
    Clash Royale
</p>

CSS: 

.game {
    color: purple;
    font-size: 20px;
}

15. Несколько свойств

h1 {
    color: white;
    background: #2563eb;
    font-size: 40px;
    text-align: center;
}

16. Пример простой страницы

body {
    background: #f1f5f9;
    font-family: Arial, sans-serif;
}

h1 {
    color: #2563eb;
    text-align: center;
    font-size: 42px;
}

    color: #7c3aed;
}

p {
    font-size: 18px;
}

img {
    width: 300px;
    border-radius: 20px;
}

.game {
    color: #dc2626;
}

17. Где лучше хранить CSS?

Структура проекта: 

my-site/

├── index.html
└── style.css

В HTML: 

<head>

    <meta charset="UTF-8">

    <title>
        Мой сайт
    </title>

    <link
        rel="stylesheet"
        href="style.css"
    >

</head>
