```html Практика №4 — CSS

Практическая работа №4

Оформляем сайт с помощью CSS

Задача

Возьми сайт с прошлого занятия или создай новую страницу «Мои любимые игры».

Теперь нужно сделать её красивее с помощью CSS.

1. Создай style.css

Структура проекта: 

my-site/

├── index.html
└── style.css

2. Подключи CSS

Внутри <head>: 

<link rel="stylesheet" href="style.css">

3. Измени фон сайта

В style.css: 

body {
    background: #f1f5f9;
}
Выбери свой цвет фона.

4. Измени шрифт

body {
    background: #f1f5f9;
    font-family: Arial, sans-serif;
}

5. Оформи главный заголовок

h1 {
    color: #2563eb;
    font-size: 42px;
    text-align: center;
}
Выбери свой цвет заголовка.

6. Оформи h2

h2 {
    color: #7c3aed;
    font-size: 28px;
}

7. Измени текст

p {
    font-size: 18px;
}

8. Оформи изображение

img {
    width: 350px;
    border-radius: 20px;
}
Попробуй менять border-radius и посмотри на результат.

9. Создай класс

В HTML: 

<p class="favorite">
    Это моя любимая игра!
</p>

В CSS: 

.favorite {
    color: red;
    font-size: 22px;
}

10. Сделай класс для игрового списка

HTML: 

<li class="game">
    Clash Royale
</li>

<li class="game">
    Elden Ring
</li>

<li class="game">
    League of Legends
</li>

CSS: 

.game {
    color: #2563eb;
    font-size: 20px;
}

11. Оформи ссылку

a {
    color: #7c3aed;
    font-size: 18px;
}

12. Итоговый CSS

Пример структуры: 

body {
    background: #f1f5f9;
    font-family: Arial, sans-serif;
}

h1 {
    color: #2563eb;
    font-size: 42px;
    text-align: center;
}

h2 {
    color: #7c3aed;
    font-size: 28px;
}

p {
    font-size: 18px;
}

img {
    width: 350px;
    border-radius: 20px;
}

a {
    color: #7c3aed;
}

.favorite {
    color: red;
    font-size: 22px;
}

.game {
    color: #2563eb;
    font-size: 20px;
}

Обязательно измени пример под себя

Не оставляй все цвета такими же, как в подсказке.

Сделай свой дизайн.

13. Проверь другие страницы

Если у тебя есть: 

index.html
games.html
about.html

подключи один style.css ко всем страницам.

Например: 

<link rel="stylesheet" href="style.css">
Один CSS-файл может оформлять сразу несколько HTML-страниц.

Проверка

☐ Создан style.css

☐ CSS подключён через link

☐ Изменён фон страницы

☐ Изменён шрифт

☐ Оформлен h1

☐ Оформлен h2

☐ Изменён размер текста

☐ Картинка имеет заданную ширину

☐ Использован border-radius

☐ Использован минимум один class

☐ Есть свой дизайн, а не полная копия примера

Готово?

Покажи сайт преподавателю.

Если стили подключены правильно — получи пароль от Extra.

```
