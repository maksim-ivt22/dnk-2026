Grid и адаптивность

Результат занятия

Вы построите страницу кружков: карточки будут занимать одну, две или три колонки в зависимости от ширины экрана, а боковой блок на широком экране окажется рядом с основным содержимым.

До начала вспомните HTML, подключение CSS, модель блока и Flexbox из предыдущих занятий. Нужны редактор кода и браузер.

Дополнительное задание выполняется после основной работы и не входит в эти 180 минут.

Как работает Grid

Grid раскладывает непосредственных потомков контейнера по строкам и колонкам. Например, три элемента article попадут в сетку после того, как их родителю class="cards" задано display: grid.

<div class="cards">
  <article>Робототехника</article>
  <article>Дизайн</article>
  <article>Программирование</article>
</div>
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

repeat(3, 1fr) создаёт три одинаковые колонки. Единица fr обозначает долю доступного пространства после вычета промежутков. Свойство gap задаёт расстояние между строками и между колонками.

Пример: ширина самой сетки — 1000 px, два промежутка по 20 px. На колонки остаётся 960 px, поэтому каждая из трёх занимает 320 px. Если у сетки есть padding, сначала учитывают и его.

Карточек может быть больше, чем колонок: дополнительные элементы автоматически переходят на следующую строку. Их порядок в HTML при этом сохраняется.

Гибкие размеры и занимаемые колонки

Запись minmax(0, 2fr) minmax(0, 1fr) создаёт две колонки: первая получает две доли, вторая — одну. Минимум 0 разрешает колонке сужаться; длинному тексту внутри также может понадобиться overflow-wrap: anywhere.

.layout {
  display: grid;
  grid-template-columns: minmax(0, 2fr) minmax(0, 1fr);
  gap: 16px;
}

.site-header, .site-footer {
  grid-column: 1 / -1;
}

Правило grid-column: 1 / -1 растягивает элемент от первой до последней линии явной сетки. Здесь шапка и подвал занимают всю ширину, а основной раздел и боковой блок могут стоять рядом. Расположение зависит и от порядка элементов в HTML.

Адаптивная страница

Адаптивность помогает странице оставаться удобной при разной ширине окна. Сначала зададим одну колонку для узкого экрана, затем добавим изменения для более широких экранов.

.cards {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

@media (min-width: 600px) {
  .cards { grid-template-columns: repeat(2, minmax(0, 1fr)); }
}

@media (min-width: 900px) {
  .cards { grid-template-columns: repeat(3, minmax(0, 1fr)); }
}

При ширине окна от 600 px действуют правила для двух колонок; от 900 px действуют оба условия, но последнее правило с той же специфичностью задаёт три. Значения 600 и 900 px выбраны для этого макета: проверяйте, где именно вашему содержимому становится тесно.

Поместите в <head> страницы строку ниже, чтобы мобильный браузер использовал ширину устройства как ширину области просмотра:

<meta name="viewport" content="width=device-width, initial-scale=1">

Сетка, которая сама выбирает число колонок

Иногда удобно задавать минимальную ширину карточки, а не количество колонок на каждом размере. Сузьте окно браузера и посмотрите, как перестроится пример.

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 12rem), 1fr));

auto-fit подбирает число колонок по доступной ширине; minmax задаёт их пределы. Вложенный min(100%, 12rem) позволяет одной колонке уместиться даже в контейнере уже 12rem. Такой способ зависит от ширины контейнера, а приведённые выше media queries — от ширины окна.

Grid и Flexbox вместе

Grid удобен для строк и колонок всей страницы или набора карточек. Flexbox удобен, например, для выравнивания ссылок меню в одной строке с переносом. В одной странице можно использовать оба способа: Grid снаружи, Flexbox внутри шапки.

Самопроверка: сколько колонок будет при ширине окна 768 px в примере с media queries?

Две: условие от 600 px выполнено, а от 900 px — ещё нет. При 375 px останется одна, при 1200 px будет три.
