Страница школьных кружков

Создайте отдельную папку grid-practice, а в ней файлы index.html и style.css. Это будет ваша учебная страница. План занятия с перерывом приведён в теории.

1. Подготовьте разметку

Вставьте в grid-practice/index.html код ниже. Он содержит три карточки. Скопируйте одну из них и замените её содержимое так, чтобы получилось не меньше шести разных кружков.

<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Кружки школы</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="layout" id="top">
    <header class="site-header">
      <a class="brand" href="#top">Школьные кружки</a>
      <nav aria-label="Разделы страницы">
        <a href="#clubs">Кружки</a>
        <a href="#contacts">Контакты</a>
      </nav>
    </header>
    <main id="clubs">
      <h1>Выберите кружок</h1>
      <p>Занятия для тех, кто любит создавать и исследовать.</p>
      <div class="cards">
        <article class="card"><h2>Робототехника</h2><p>Собираем модели.</p><p>Понедельник, 16:00</p></article>
        <article class="card"><h2>Дизайн</h2><p>Изучаем цвет и форму.</p><p>Вторник, 15:00</p></article>
        <article class="card"><h2>Программирование</h2><p>Создаём сайты.</p><p>Среда, 16:00</p></article>
      </div>
    </main>
    <aside class="notice">
      <h2>Как записаться</h2>
      <p>Выберите кружок и обратитесь к преподавателю.</p>
    </aside>
    <footer class="site-footer" id="contacts">
      <p>Контакты: кабинет 101, после уроков.</p>
    </footer>
  </div>
</body>
</html>

Откройте страницу в браузере. Пока блоки идут один за другим — это ожидаемо. Убедитесь, что ссылки меню переходят к разделам страницы.

2. Задайте базовое оформление

Вставьте в style.css базовые правила. Контейнер с классом layout ограничивает ширину страницы. Шапка использует Flexbox; карточки пока выстраиваются в одну колонку с помощью Grid.

* { box-sizing: border-box; }
body { margin: 0; font-family: Arial, sans-serif; line-height: 1.5; background: #f1f5f9; color: #1e293b; }
.layout { max-width: 1100px; margin: 0 auto; padding: 16px; display: grid; gap: 16px; }
.site-header, .site-footer { padding: 20px; background: #0f172a; color: white; border-radius: 12px; }
.site-header { display: flex; flex-wrap: wrap; justify-content: space-between; align-items: center; gap: 12px; }
.site-header a { color: white; }
.site-header nav { display: flex; flex-wrap: wrap; gap: 16px; }
.brand { font-weight: bold; }
.cards { display: grid; grid-template-columns: 1fr; gap: 16px; }
.card, .notice { min-width: 0; padding: 16px; background: white; border: 1px solid #cbd5e1; border-radius: 12px; overflow-wrap: anywhere; }
.card h2 { margin-top: 0; font-size: 1.2rem; }

Обновите браузер и проверьте, что стили применились. Если нет, сверьте имя CSS-файла и путь в теге link.

3. Исследуйте сетку

  1. Временно замените 1fr у .cards на repeat(3, 1fr). Как разместились шесть карточек?
  2. Поменяйте gap: 16px у .cards на 32px и найдите промежутки между строками и колонками.
  3. Верните 1fr и gap: 16px. На следующем шаге вы настроите количество колонок для разных экранов.

4. Сделайте карточки адаптивными

В конце CSS добавьте условия: от 600 px — две колонки, от 900 px — три. При меньшей ширине остаётся одна колонка из базового правила.

@media (min-width: 600px) {
  .cards { grid-template-columns: repeat(2, minmax(0, 1fr)); }
}

@media (min-width: 900px) {
  .cards { grid-template-columns: repeat(3, minmax(0, 1fr)); }
}

Сохраните файл и изменяйте ширину окна. Обратите внимание, что условие проверяет ширину окна, а ширина самих карточек зависит от свободного места внутри .cards.

5. Перестройте страницу целиком

Внутрь уже созданного условия @media (min-width: 900px) добавьте правила ниже, рядом с правилом .cards. На узком экране .layout по умолчанию остаётся одноколоночной сеткой.

.layout { grid-template-columns: minmax(0, 2fr) minmax(0, 1fr); }
.site-header, .site-footer { grid-column: 1 / -1; }

На широком экране шапка и подвал должны занимать две колонки, main — левую, aside — правую. Проверьте, что в HTML эти элементы являются непосредственными потомками .layout и идут в указанном порядке.

6. Проверьте разные экраны

В браузере откройте инструменты разработчика клавишей F12 или Ctrl+Shift+I и включите режим устройства кнопкой с изображением телефона и планшета. Выставьте ширину окна страницы и проверьте:

  • 375 px: одна колонка карточек, информационный блок под ними.
  • 768 px: две колонки карточек, информационный блок под ними.
  • 1200 px: три колонки карточек, информационный блок справа.

Для каждого размера проверьте шапку, читаемость текста и отсутствие горизонтальной прокрутки всей страницы. Увеличьте масштаб браузера до 200%, затем верните обычный масштаб.

7. Найдите и исправьте проблему

  1. Временно добавьте в одну карточку очень длинное слово без пробелов. Убедитесь, что оно переносится и не раздвигает страницу. Отключите overflow-wrap, сравните и верните правило.
  2. В инструментах разработчика выделите .cards и отключите display: grid. Что произошло? Включите правило обратно.
  3. Если число колонок не меняется, проверьте закрывающие фигурные скобки, порядок media queries и ширину окна страницы. Если боковой блок оказался не там, проверьте порядок элементов и grid-column шапки и подвала.

8. Самостоятельное изменение и сдача

Сделайте первую карточку заметнее: добавьте ей класс featured, измените цвет границы и внутри условия от 600 px растяните её на две колонки с помощью grid-column: span 2. На узком экране она должна занимать одну колонку. Добавьте седьмую карточку и проверьте, как сетка размещает её без дополнительных правил.

Покажите преподавателю страницу на трёх размерах и код обоих файлов. Объясните, почему на широком экране используются и Grid, и Flexbox, что делает viewport и какое правило переносит длинное слово.
