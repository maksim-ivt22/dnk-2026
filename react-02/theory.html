React №2

Массивы, map() и формы

React map() Forms useState
Цель: научиться хранить данные в массиве, выводить элементы через map() и добавлять новые элементы через форму.

1. Повторяем прошлый урок

Мы уже умеем создавать компонент: 

function GameCard({ title, genre }) {

    return (
        <div>

            <h2>{title}</h2>

            <p>
                Жанр: {genre}
            </p>

        </div>
    );

}

И использовать его: 

<GameCard
    title="Elden Ring"
    genre="Action RPG"
/>

2. Проблема

Если игр много, писать вручную: 

<GameCard ... />
<GameCard ... />
<GameCard ... />
<GameCard ... />
<GameCard ... />

неудобно.

Лучше хранить данные в массиве.

3. Массив объектов

const games = [

    {
        id: 1,
        title: "Clash Royale",
        genre: "Strategy"
    },

    {
        id: 2,
        title: "League of Legends",
        genre: "MOBA"
    },

    {
        id: 3,
        title: "Elden Ring",
        genre: "Action RPG"
    }

];
Каждый объект — одна игра. А массив хранит все игры вместе.

4. Что делает map()?

map() перебирает массив и создаёт что-то для каждого элемента. 

games.map(game => {
    console.log(game.title);
});

В React можно создавать компоненты: 

{games.map(game => (

    <GameCard
        title={game.title}
        genre={game.genre}
    />

))}
массив games ↓ map() ↓ каждая игра ↓ GameCard

5. key

React просит у элементов списка уникальный key. 

{games.map(game => (

    <GameCard
        key={game.id}
        title={game.title}
        genre={game.genre}
    />

))}
Обычно для key используют уникальный id.

6. Храним массив в state

Если список будет изменяться, храним его в useState. 

const [games, setGames] = useState([

    {
        id: 1,
        title: "Clash Royale",
        genre: "Strategy"
    },

    {
        id: 2,
        title: "Elden Ring",
        genre: "Action RPG"
    }

]);

7. Теперь форма

Сделаем поле ввода: 

<input
    type="text"
    placeholder="Название игры"
/>

Но React должен знать, что пользователь ввёл.

8. State для input

const [title, setTitle] = useState("");

Теперь связываем input со state: 

<input
    type="text"
    value={title}
    onChange={(event) =>
        setTitle(event.target.value)
    }
/>

Что здесь происходит?

event.target.value

Это текст, который сейчас находится в input.

пользователь пишет ↓ onChange ↓ setTitle(...) ↓ title изменяется

9. Форма

<form>

    <input
        value={title}
        onChange={(event) =>
            setTitle(event.target.value)
        }
    />

    <button>
        Добавить
    </button>

</form>

10. Проблема формы

По умолчанию форма пытается перезагрузить страницу.

Поэтому: 

function handleSubmit(event) {

    event.preventDefault();

}
preventDefault() отменяет стандартное поведение формы.

11. Добавляем новый объект

Создаём новую игру: 

const newGame = {

    id: Date.now(),

    title: title,

    genre: "Не указан"

};

12. Добавляем объект в массив

setGames([
    ...games,
    newGame
]);

...games означает: взять все старые элементы массива.

Потом добавляем: 

newGame
старые игры + новая игра ↓ новый массив ↓ setGames(...)

13. Очищаем input

После добавления: 

setTitle("");

14. Полный пример App.jsx

import { useState } from "react";
import GameCard from "./components/GameCard";


function App() {

    const [games, setGames] = useState([

        {
            id: 1,
            title: "Clash Royale",
            genre: "Strategy"
        },

        {
            id: 2,
            title: "Elden Ring",
            genre: "Action RPG"
        }

    ]);


    const [title, setTitle] = useState("");


    function handleSubmit(event) {

        event.preventDefault();


        const newGame = {

            id: Date.now(),

            title: title,

            genre: "Не указан"

        };


        setGames([
            ...games,
            newGame
        ]);


        setTitle("");

    }


    return (

        <div className="container">


            <h1>
                Мои игры
            </h1>


            <form onSubmit={handleSubmit}>

                <input
                    type="text"
                    value={title}
                    onChange={(event) =>
                        setTitle(event.target.value)
                    }
                    placeholder="Название игры"
                />


                <button type="submit">
                    Добавить
                </button>

            </form>


            <div className="cards">

                {games.map(game => (

                    <GameCard
                        key={game.id}
                        title={game.title}
                        genre={game.genre}
                    />

                ))}

            </div>


        </div>

    );

}

export default App;
