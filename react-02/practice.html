Создаём приложение «Моя библиотека игр»

Задача

Сделай React-приложение, в котором можно:

  • посмотреть список игр;
  • добавить новую игру;
  • указать жанр;
  • автоматически вывести новую карточку.

1. Начальный массив

const [games, setGames] = useState([

    {
        id: 1,
        title: "Clash Royale",
        genre: "Strategy"
    },

    {
        id: 2,
        title: "League of Legends",
        genre: "MOBA"
    },

    {
        id: 3,
        title: "Elden Ring",
        genre: "Action RPG"
    }

]);

2. Выведи игры через map()

{games.map(game => (

    <GameCard
        key={game.id}
        title={game.title}
        genre={game.genre}
    />

))}
Нельзя вручную писать три <GameCard />. Все карточки должны создаваться через map().

3. Добавь форму

Нужно два поля:

  • название игры;
  • жанр.

Создай состояния: 

const [title, setTitle] = useState("");

const [genre, setGenre] = useState("");

4. Поле названия

<input
    type="text"
    value={title}
    onChange={(event) =>
        setTitle(event.target.value)
    }
    placeholder="Название игры"
/>

5. Поле жанра

<input
    type="text"
    value={genre}
    onChange={(event) =>
        setGenre(event.target.value)
    }
    placeholder="Жанр"
/>

6. Функция добавления

function handleSubmit(event) {

    event.preventDefault();


    const newGame = {

        id: Date.now(),

        title: title,

        genre: genre

    };


    setGames([
        ...games,
        newGame
    ]);


    setTitle("");

    setGenre("");

}

7. Подключи функцию к form

<form onSubmit={handleSubmit}>

    ...

</form>

8. Добавь кнопку

<button type="submit">
    Добавить игру
</button>

9. Не добавляй пустую игру

В начало handleSubmit добавь: 

if (title.trim() === "") {
    return;
}
trim() убирает пробелы в начале и конце строки.

10. Если жанр пустой

Можно сделать: 

genre: genre.trim() === ""
    ? "Не указан"
    : genre

11. GameCard

function GameCard({ title, genre }) {

    return (

        <div className="card">

            <h2>
                {title}
            </h2>

            <p>
                🎮 Жанр: {genre}
            </p>

        </div>

    );

}

export default GameCard;

☐ Есть поле жанра
