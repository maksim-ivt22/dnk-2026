React №2 — Extra

Удаление, подсчёт и фильтрация списка

Задача

Твоё приложение уже умеет добавлять игры. Теперь сделай его удобнее.

Добавь:
  1. удаление игры;
  2. количество игр;
  3. выбор жанра через select;
  4. фильтрацию списка.

1. Удаление игры

Создай функцию: 

function deleteGame(id) {

    const newGames = games.filter(
        game => game.id !== id
    );

    setGames(newGames);

}

Что делает filter()?

filter() создаёт новый массив, оставляя только нужные элементы.

Передай функцию в GameCard: 

<GameCard
    key={game.id}
    id={game.id}
    title={game.title}
    genre={game.genre}
    deleteGame={deleteGame}
/>

В компоненте: 

function GameCard({
    id,
    title,
    genre,
    deleteGame
}) {

    return (

        <div className="card">

            <h2>
                {title}
            </h2>

            <p>
                {genre}
            </p>

            <button
                onClick={() =>
                    deleteGame(id)
                }
            >
                🗑 Удалить
            </button>

        </div>

    );

}

5. Фильтруем массив

const visibleGames = filter === "Все"

    ? games

    : games.filter(
        game => game.genre === filter
    );

Теперь вместо: 

games.map(...)

используем: 

visibleGames.map(...)

🚀 HARD

Добавь поиск по названию.

Создай: 

const [search, setSearch] = useState("");

Input: 

<input
    type="text"
    value={search}
    onChange={(event) =>
        setSearch(event.target.value)
    }
    placeholder="Поиск..."
/>

И попробуй: 

const searchedGames = visibleGames.filter(
    game =>

        game.title
            .toLowerCase()
            .includes(
                search.toLowerCase()
            )
);

После этого выводи: 

searchedGames.map(...)

SUPER HARD

Сделай кнопку: 

Очистить все игры

По нажатию: 

setGames([]);

Но перед очисткой попробуй использовать: 

confirm()

Например: 

if (confirm("Удалить все игры?")) {
    setGames([]);
}
