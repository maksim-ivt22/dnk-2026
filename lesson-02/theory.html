1. Повторяем прошлое занятие

Вопрос: что такое HTML?

HTML — язык разметки, который описывает содержимое веб-страницы.

С помощью HTML браузер понимает:

  • где заголовок;
  • где текст;
  • где изображение;
  • где ссылка;
  • где список.

Базовая структура HTML

<!DOCTYPE html>

<html lang="ru">

<head>
    <meta charset="UTF-8">
    <title>Мой сайт</title>
</head>

<body>

    Здесь находится содержимое сайта

</body>

</html>
html │ ├── head │ └── информация о странице │ └── body └── то, что видит пользователь
Всё, что мы хотим показать пользователю, размещаем внутри тега <body>.

2. Что такое HTML-тег?

HTML-страница состоит из специальных команд — тегов.

Например:

<p>Привет! Я изучаю HTML.</p>

Здесь:

  • <p> — открывающий тег;
  • текст — содержимое;
  • </p> — закрывающий тег.
Большинство HTML-тегов имеют начало и конец.

Пример

<h1>Мой первый сайт</h1>

Но некоторые теги не требуют закрывающего тега.

Например:

<img src="cat.jpg" alt="Кот">

3. Заголовки

Заголовки помогают разделить страницу на части.

<h1>

Главный заголовок страницы

<h2>

Название раздела

<h3>

Подраздел

Пример

<h1>Мой сайт о компьютерных играх</h1>

<h2>Мои любимые игры</h2>

<h3>Minecraft</h3>

Мой сайт о компьютерных играх

Мои любимые игры

Minecraft

<h1> — не просто большой текст. Это главный заголовок страницы.

4. Обычный текст

Для абзаца используется тег: 

<p></p>

Пример

<p>
    Меня зовут Максим.
    Я учусь в 1 курсе магистратуры.
</p>

Меня зовут Максим. Я учусь в 1 курсе магистратуры.

Если нужно несколько абзацев — используем несколько тегов <p>. 

<p>Я изучаю программирование.</p>

<p>Мне нравится создавать сайты.</p>

Выделение текста

Для важного текста: 

<strong>важный текст</strong>

Для смыслового акцента: 

<em>текст</em>

Пример

<p>
    Я изучаю
    <strong>веб-программирование</strong>.
</p>

Я изучаю веб-программирование.

5. Ссылки

Для создания ссылки используется тег: 

<a></a>

Но браузеру нужно сообщить, куда должна вести ссылка. 

<a href="https://google.com">
    Открыть Google
</a>

Что такое href?

href — это атрибут.

Атрибут передаёт тегу дополнительную информацию.

<a href="https://youtube.com">YouTube</a> a → тег ссылки href → куда перейти https → адрес сайта YouTube → текст ссылки

Открыть в новой вкладке

<a
    href="https://youtube.com"
    target="_blank"
>
    YouTube
</a>
Пример ссылки

6. Изображения

Для изображения используется тег: 

<img>

Но нужно указать адрес изображения. 

<img
    src="https://picsum.photos/400/250"
    alt="Пример изображения"
>
src

Где находится изображение

alt

Описание изображения

Изображение из папки проекта

Представим, что структура проекта выглядит так:

my-site │ ├── index.html │ └── cat.jpg

Тогда пишем:

<img
    src="cat.jpg"
    alt="Рыжий кот"
>
src — откуда взять картинку.
alt — что изображено на картинке.

Зачем нужен alt?

Если изображение не загрузится, браузер сможет показать его описание.

✅ Хорошо 
<img
    src="dog.jpg"
    alt="Белая собака играет с мячом"
>
❌ Плохо 
<img
    src="dog.jpg"
    alt="картинка"
>

7. Списки

В HTML есть два основных вида списков.

Ненумерованный список

Используем, если порядок не важен. 

<ul>

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ul>
  • HTML
  • CSS
  • JavaScript

<ul> — весь список.

<li> — один элемент списка.

Нумерованный список

Используем, когда порядок важен. 

<ol>

    <li>Открыть VS Code</li>
    <li>Создать index.html</li>
    <li>Написать код</li>
    <li>Открыть страницу</li>

</ol>
  1. Открыть VS Code
  2. Создать index.html
  3. Написать код
  4. Открыть страницу

8. Вложенность тегов

Один HTML-тег может находиться внутри другого.

Пример

<p>

    Мой любимый сайт —

    <a href="https://youtube.com">
        YouTube
    </a>

</p>
<p> текст <a> ссылка </a> </p>
Главное правило: если тег открыли внутри другого тега, его нужно закрыть раньше внешнего.
✅ Правильно 
<p>
    <strong>
        Привет!
    </strong>
</p>
❌ Неправильно 
<p>
    <strong>
        Привет!
</p>
    </strong>

9. Собираем всё вместе

Теперь мы можем создать уже нормальную HTML-страницу. 

<!DOCTYPE html>

<html lang="ru">

<head>

    <meta charset="UTF-8">

    <title>Мои любимые игры</title>

</head>


<body>


    <h1>Мои любимые игры</h1>


    <p>
        Привет! Меня зовут Максим.
        Я изучаю
        <strong>веб-программирование</strong>.
    </p>


    <h2>Во что я сейчас играю</h2>


    <ol>

        <li>Clash Royale</li>
        <li>League of Legends</li>
        <li>Elden Ring</li>

    </ol>

    <h2>Clash Royale</h2>


    <img
        src=""
        alt="Изображение Clash Royale"
    >


    <p>
        Мне нравится поднимать трофеи,
        собирать колоды и играть против других игроков.
    </p>


    <h3>Почему мне нравится эта игра?</h3>


    <ul>

        <li>Короткие и динамичные матчи</li>
        <li>Можно собирать разные колоды</li>
        <li>Интересно соревноваться с другими игроками</li>

    </ul>


    <a href="https://supercell.com/en/games/clashroyale/"
        target="_blank"
    >
        Официальный сайт Clash Royale
    </a>


</body>

</html>
