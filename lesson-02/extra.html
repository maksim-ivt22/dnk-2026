Дополнительное задание

Ты уже закончил основную практику — поэтому теперь попробуй сделать небольшой сайт из нескольких HTML-страниц.

Задача

Создай сайт «Мои любимые игры» из трёх страниц.

Страница 1 — Главная

Файл: 

index.html

На странице должны быть:

  • заголовок сайта;
  • небольшой текст о тебе;
  • список любимых игр;
  • ссылки на две другие страницы.

Страница 2 — Любимая игра

Создай файл: 

game.html

Добавь:

  • название любимой игры;
  • изображение;
  • описание игры;
  • список причин, почему она тебе нравится;
  • ссылку на официальный сайт игры;
  • ссылку обратно на главную страницу.

Страница 3 — Обо мне

Создай: 

about.html

Добавь:

  • небольшой рассказ о себе;
  • свои интересы;
  • ТОП-3 игр, фильмов или увлечений;
  • ссылку обратно на главную страницу.

В результате

Папка проекта должна выглядеть так: 

my-games/

├── index.html
├── game.html
└── about.html

Как соединить страницы?

С главной страницы можно перейти на страницу игры: 

<a href="game.html">
    Моя любимая игра
</a>

И на страницу «Обо мне»: 

<a href="about.html">
    Обо мне
</a>

А чтобы вернуться обратно: 

<a href="index.html">
    ← На главную
</a>
Обрати внимание: здесь нет адреса вида https://....

Мы можем делать ссылки прямо на другие HTML-файлы нашего сайта.

Обязательные условия

Перед тем как показать работу преподавателю, проверь:

☐ Есть три HTML-файла

☐ С главной страницы открывается game.html

☐ С главной страницы открывается about.html

☐ С других страниц можно вернуться на главную

☐ Есть изображение

☐ Есть <ul>

☐ Есть <ol>

☐ Есть внешняя ссылка на другой сайт

☐ Используются <h1>, <h2> и <p>

Уровень HARD

Если всё готово — попробуй без помощи преподавателя:

  1. Создать четвёртую страницу games.html.
  2. Добавить туда список из пяти игр.
  3. Для каждой игры добавить ссылку на официальный сайт.
  4. Узнать самостоятельно, что делает тег <hr>.
  5. Узнать самостоятельно, как сделать картинку ссылкой.

Суперзадание

Попробуй самостоятельно понять, что произойдёт, если написать: 

<a href="game.html">

    <img
        src="game.jpg"
        alt="Моя любимая игра"
    >

</a>

Сначала предположи результат, а потом проверь его в браузере.
