React — Практическая работа

Создаём приложение «Мои любимые игры»

Задача

Создай React-приложение, которое показывает карточки твоих любимых игр.

Каждая карточка должна содержать:
  • название игры;
  • жанр;
  • короткое описание;
  • счётчик лайков;
  • кнопку «Лайк».

1. Создай проект

npm create vite@latest

Выбери:

React
JavaScript

Затем:

cd имя-проекта

npm install

npm run dev

2. Подготовь структуру

src/
│
├── components/
│   └── GameCard.jsx
│
├── App.jsx
├── main.jsx
└── index.css

3. Создай GameCard

Компонент должен принимать: 

title
genre
description
Подсказка: данные передаются через props. 
function GameCard({
    title,
    genre,
    description
}) {

    return (
        <div className="card">

            <h2>
                {title}
            </h2>

            <p>
                Жанр: {genre}
            </p>

            <p>
                {description}
            </p>

        </div>
    );

}

export default GameCard;

4. Используй компонент три раза

В App.jsx: 

import GameCard from "./components/GameCard";

function App() {

    return (
        <div className="container">

            <h1>
                Во что я играю
            </h1>


            <div className="cards">

                <GameCard
                    title="Clash Royale"
                    genre="Strategy"
                    description="Карточная PvP игра"
                />

                <GameCard
                    title="League of Legends"
                    genre="MOBA"
                    description="Командная соревновательная игра"
                />

                <GameCard
                    title="Elden Ring"
                    genre="Action RPG"
                    description="Большой мир и сложные боссы"
                />

            </div>

        </div>
    );

}

export default App;
Не обязательно использовать именно эти игры. Выбери свои.

5. Добавь useState

Теперь у каждой карточки должен быть свой счётчик лайков.

Добавь: 

import { useState } from "react";

Внутри компонента: 

const [likes, setLikes] = useState(0);

6. Покажи количество лайков

<p>
    Лайков: {likes}
</p>

7. Добавь кнопку

<button
    onClick={() => setLikes(likes + 1)}
>
    Лайк
</button>
