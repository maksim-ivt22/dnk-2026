React — Дополнительное задание

Улучшаем компонент GameCard

Задача

Основное приложение уже работает. Теперь сделай карточки более интерактивными.

Нужно добавить:
  1. кнопку увеличения лайков;
  2. кнопку уменьшения лайков;
  3. запрет отрицательных лайков;
  4. кнопку показа описания;
  5. условное отображение текста.

1. Добавь кнопку ➖

Сейчас есть: 

<button
    onClick={() => setLikes(likes + 1)}
>
    Лайк
</button>

Добавь вторую кнопку: 

<button
    onClick={() => setLikes(likes - 1)}
>
    Убрать лайк
</button>

2. Исправь проблему

Сейчас можно получить: 

Лайков: -1
Лайков: -2
Лайков: -3

Это неправильно.

Добавь проверку: 

<button
    onClick={() => {

        if (likes > 0) {
            setLikes(likes - 1);
        }

    }}
>

    Убрать лайк

</button>
Теперь количество лайков не должно становиться меньше нуля.

3. Добавь ещё один state

Создай состояние: 

const [showDescription, setShowDescription]
    = useState(false);

Здесь:

  • false — описание скрыто;
  • true — описание показано.

4. Добавь кнопку

<button
    onClick={() =>
        setShowDescription(!showDescription)
    }
>

    Показать / скрыть описание

</button>

5. Условный рендеринг

Вместо: 

<p>
    {description}
</p>

напиши: 

{showDescription && (
    <p>
        {description}
    </p>
)}
Это означает:

если showDescription равно true, показать описание.

6. Измени текст кнопки

Сейчас кнопка всегда пишет: 

Показать / скрыть описание

Попробуй сделать лучше: 

<button
    onClick={() =>
        setShowDescription(!showDescription)
    }
>

    {showDescription
        ? "Скрыть описание"
        : "Показать описание"}

</button>

7. Как теперь должен выглядеть GameCard?

import { useState } from "react";

function GameCard({
    title,
    genre,
    description
}) {

    const [likes, setLikes] = useState(0);

    const [showDescription, setShowDescription]
        = useState(false);


    return (
        <div className="card">


            <h2>
                {title}
            </h2>


            <p>
                Жанр: {genre}
            </p>


            {showDescription && (

                <p>
                    {description}
                </p>

            )}


            <p>
                Лайков: {likes}
            </p>


            <button
                onClick={() =>
                    setLikes(likes + 1)
                }
            >
                Лайк
            </button>


            <button
                onClick={() => {

                    if (likes > 0) {
                        setLikes(likes - 1);
                    }

                }}
            >
                Убрать лайк
            </button>


            <button
                onClick={() =>
                    setShowDescription(
                        !showDescription
                    )
                }
            >

                {showDescription
                    ? "Скрыть описание"
                    : "Показать описание"}

            </button>


        </div>
    );

}

export default GameCard;
