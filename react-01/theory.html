1. Что такое React?

React — библиотека JavaScript для создания пользовательских интерфейсов.

До этого мы создавали сайт примерно так: 

<h1>Мой сайт</h1>

<p>Какой-то текст</p>

<button>Нажми</button>

В React страницу удобно делить на небольшие части — компоненты.

App
↓
Header
↓
GameCard
↓
Footer

2. Что такое компонент?

Компонент — это отдельная часть интерфейса.

Например:

  • шапка сайта;
  • карточка игры;
  • кнопка;
  • меню;
  • форма.
Компонент можно написать один раз и использовать много раз.

4. Какие файлы нам нужны?

src/
│
├── App.jsx
├── main.jsx
└── index.css

Пока достаточно понимать:

  • App.jsx — главный компонент;
  • main.jsx — запускает React;
  • index.css — стили.

5. Первый React-компонент

Открываем App.jsx. 

function App() {

    return (
        <div>

            <h1>Привет, React!</h1>

            <p>
                Это моё первое React-приложение.
            </p>

        </div>
    );

}

export default App;

Разбираем

function App()

Создаёт компонент. 

return

Возвращает то, что будет показано на странице. 

export default App;

Позволяет использовать компонент в других файлах.

6. JSX

В React используется JSX.

JSX похож на HTML: 

<h1>Привет</h1>

Но находится прямо внутри JavaScript.

В React вместо class используется className.

HTML: 

<div class="card">

React: 

<div className="card">

7. JavaScript внутри JSX

JavaScript можно вставлять через фигурные скобки: 

function App() {

    const name = "Максим";

    return (
        <div>

            <h1>
                Привет, {name}!
            </h1>

        </div>
    );

}

Можно даже: 

<p>
    2 + 2 = {2 + 2}
</p>

9. Подключаем компонент

В App.jsx: 

import GameCard from "./components/GameCard";

function App() {

    return (
        <div>

            <h1>Мои игры</h1>

            <GameCard />

        </div>
    );

}

export default App;
Компонент React можно использовать почти как собственный HTML-тег: <GameCard />

10. Props

Сейчас все карточки будут одинаковыми.

Чтобы передавать данные в компонент, используются props.

В App.jsx:

<GameCard
    title="Clash Royale"
    description="Карточная стратегия"
/>

<GameCard
    title="League of Legends"
    description="Командная MOBA"
/>

<GameCard
    title="Elden Ring"
    description="Action RPG"
/>

В GameCard.jsx: 

function GameCard({ title, description }) {

    return (
        <div>

            <h2>{title}</h2>

            <p>{description}</p>

        </div>
    );

}

export default GameCard;
App
↓ передаёт props
GameCard
↓ title + description

11. State

Теперь сделаем приложение интерактивным.

Нам понадобится: 

useState

Например, создадим счётчик: 

import { useState } from "react";

function App() {

    const [count, setCount] = useState(0);

    return (
        <div>

            <h1>
                Нажатий: {count}
            </h1>

            <button
                onClick={() => setCount(count + 1)}
            >
                Нажми
            </button>

        </div>
    );

}

export default App;

Что означает эта строка?

const [count, setCount] = useState(0);
  • count — текущее значение;
  • setCount — изменяет значение;
  • 0 — начальное значение.

12. Событие onClick

В обычном JavaScript мы использовали: 

addEventListener("click", ...)

В React: 

<button
    onClick={() => alert("Привет!")}
>
    Нажми
</button>

13. Карточка с лайками

import { useState } from "react";

function GameCard({ title, description }) {

    const [likes, setLikes] = useState(0);

    return (
        <div className="card">

            <h2>{title}</h2>

            <p>{description}</p>

            <p>
                Лайков: {likes}
            </p>

            <button
                onClick={() => setLikes(likes + 1)}
            >
                Лайк
            </button>

        </div>
    );

}

export default GameCard;
Каждый компонент GameCard будет иметь свой собственный счётчик лайков.
