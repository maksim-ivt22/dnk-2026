Занятие №3

Структура HTML-сайта

HTML Навигация Несколько страниц
Сегодня: научимся правильно делить страницу на части и создадим структуру настоящего сайта.

1. Повторяем

Мы уже знаем:

  • <h1> — заголовок;
  • <p> — текст;
  • <a> — ссылка;
  • <img> — изображение;
  • <ul> и <ol> — списки.

2. Почему нужна структура?

Большой сайт неудобно делать одной кучей тегов.

Поэтому страницу делят на логические части.

<header> Шапка сайта </header>
<nav> Меню </nav>
<main> <section> Раздел страницы </section> </main>
<footer> Подвал сайта </footer>

3. header

<header> — верхняя часть страницы.

Здесь обычно находятся:

  • название сайта;
  • логотип;
  • краткое описание.
<header>

    <h1>Games</h1>

    <p>
        Сайт о моих любимых играх
    </p>

</header>

4. nav

<nav> — навигация по сайту. 

<nav>

    <a href="index.html">
        Главная
    </a>

    <a href="games.html">
        Игры
    </a>

    <a href="about.html">
        Обо мне
    </a>

</nav>
nav обычно содержит ссылки, по которым пользователь переходит между страницами сайта.

5. main

<main> содержит главное содержимое страницы. 

<main>

    Здесь основная информация страницы

</main>
Обычно на странице используют один главный <main>.

6. section

<section> — отдельный смысловой раздел. 

<main>

    <section>

        <h2>Мои любимые игры</h2>

        <p>
            Здесь информация об играх.
        </p>

    </section>


    <section>

        <h2>Последние игры</h2>

        <p>
            Здесь другой раздел.
        </p>

    </section>

</main>

7. footer

<footer> — нижняя часть страницы. 

<footer>

    <p>
        2026 — Мой первый сайт
    </p>

</footer>

8. Полная структура страницы

<!DOCTYPE html>

<html lang="ru">

<head>

    <meta charset="UTF-8">

    <title>
        Games
    </title>

</head>


<body>


    <header>

        <h1>
            Games
        </h1>

        <p>
            Сайт о моих любимых играх
        </p>

    </header>


    <nav>

        <a href="index.html">
            Главная
        </a>

        <a href="games.html">
            Игры
        </a>

        <a href="about.html">
            Обо мне
        </a>

    </nav>


    <main>


        <section>

            <h2>
                Добро пожаловать
            </h2>

            <p>
                Это мой сайт об играх.
            </p>

        </section>


        <section>

            <h2>
                Во что я играю
            </h2>

            <ul>

                <li>Clash Royale</li>
                <li>League of Legends</li>
                <li>Elden Ring</li>

            </ul>

        </section>


    </main>


    <footer>

        <p>
            2026 — Games
        </p>

    </footer>


</body>

</html>

9. Несколько HTML-страниц

Сайт может состоять не из одного файла.

Например: 

my-site/

├── index.html
├── games.html
└── about.html

Между страницами можно переходить: 

<a href="index.html">
    Главная
</a>

<a href="games.html">
    Игры
</a>

<a href="about.html">
    Обо мне
</a>

10. Один nav на всех страницах

На каждой странице можно использовать одинаковое меню. 

<nav>

    <a href="index.html">
        Главная
    </a>

    <a href="games.html">
        Игры
    </a>

    <a href="about.html">
        Обо мне
    </a>

</nav>
Тогда пользователь сможет переходить с любой страницы на любую другую.

11. Семантические теги

Теги: 

<header>
<nav>
<main>
<section>
<footer>

называются семантическими.

Их название объясняет, какую роль выполняет часть страницы.

Итог

Сегодня нужно запомнить:

<header> — шапка
<nav> — меню
<main> — главное содержимое
<section> — раздел
<footer> — нижняя часть сайта
