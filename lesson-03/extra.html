Дополнительное задание №3

Превращаем сайт в настоящий небольшой многостраничный проект.

Задача

Основные три страницы уже готовы.

Теперь расширь сайт.

Нужно добавить:
  1. четвёртую страницу;
  2. новый пункт меню;
  3. несколько секций;
  4. переходы между страницами;
  5. папку для изображений.

1. Добавь страницу contacts.html

Создай: 

contacts.html

На ней должны быть:

  • header;
  • nav;
  • main;
  • минимум один section;
  • footer.

2. Обнови меню

Теперь меню должно быть таким: 

<nav>

    <a href="index.html">
        Главная
    </a>

    <a href="games.html">
        Игры
    </a>

    <a href="about.html">
        Обо мне
    </a>

    <a href="contacts.html">
        Контакты
    </a>

</nav>
Такое меню нужно добавить на все страницы сайта.

3. Добавь страницу одной игры

Создай: 

elden-ring.html

Или выбери любую другую игру.

На странице должны быть:

  • название игры;
  • изображение;
  • описание;
  • жанр;
  • список причин, почему тебе нравится игра;
  • ссылка обратно на games.html.

4. Сделай ссылку с games.html

Например: 

<a href="elden-ring.html">
    Подробнее про Elden Ring
</a>

5. Сделай изображение ссылкой

Попробуй: 

<a href="elden-ring.html">

    <img
        src="images/elden-ring.jpg"
        alt="Elden Ring"
    >

</a>
Теперь при нажатии на картинку пользователь перейдёт на страницу игры.

6. Улучши структуру папок

В конце проект может выглядеть так: 

game-zone/

├── index.html
├── games.html
├── about.html
├── contacts.html
├── elden-ring.html
│
└── images/
    ├── elden-ring.jpg
    ├── clash-royale.jpg
    └── lol.jpg

7. Добавь ссылки внутри страницы

Попробуй самостоятельно сделать ссылку: 

<a href="#top">
    Наверх
</a>

А в верхней части страницы: 

<header id="top">
Такая ссылка не открывает другую страницу, а перемещает пользователя внутри текущей страницы.

Проверка

☐ Есть минимум 4 страницы

☐ Меню одинаковое на всех страницах

☐ Все ссылки работают

☐ Есть отдельная страница игры

☐ Есть папка images

☐ Изображение может быть ссылкой

☐ Используются семантические теги

☐ Есть ссылка «Наверх»

HARD

Создай ещё одну страницу: 

news.html

На ней сделай минимум три раздела новостей: 

<section>

    <h2>
        Новость 1
    </h2>

    <p>
        Текст новости...
    </p>

</section>

Добавь страницу в главное меню сайта.

SUPER HARD

Самостоятельно узнай, для чего используется тег: 

<article>

Подумай: можно ли использовать его для отдельной новости или карточки игры?

Попробуй заменить несколько <section> на <article> там, где это подходит.
