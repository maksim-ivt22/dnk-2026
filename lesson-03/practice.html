Практическая работа №3

Создаём многостраничный сайт с правильной HTML-структурой.

Задача

Создай сайт «Game Zone» из трёх страниц.

Используй на страницах:
  • <header>
  • <nav>
  • <main>
  • <section>
  • <footer>

1. Создай папку проекта

game-zone

2. Создай три страницы

game-zone/

├── index.html
├── games.html
└── about.html

3. Главная страница

Открой: 

index.html

Используй такую структуру: 

<body>


    <header>

        <h1>
            Games
        </h1>

        <p>
            Сайт о моих любимых играх
        </p>

    </header>


    <nav>

        <a href="index.html">
            Главная
        </a>

        <a href="games.html">
            Игры
        </a>

        <a href="about.html">
            Обо мне
        </a>

    </nav>


    <main>


        <section>

            <h2>
                Добро пожаловать
            </h2>

            <p>
                Напиши здесь свой текст.
            </p>

        </section>


        <section>

            <h2>
                Сейчас я играю
            </h2>

            <ul>

                <li>Игра 1</li>
                <li>Игра 2</li>
                <li>Игра 3</li>

            </ul>

        </section>


    </main>


    <footer>

        <p>
            2026 — Games
        </p>

    </footer>


</body>

4. Страница games.html

На этой странице расскажи о любимых играх.

На странице должны быть:
  • тот же header;
  • то же меню nav;
  • main;
  • минимум 2 section;
  • изображение;
  • список игр;
  • footer.

5. Страница about.html

Сделай страницу «Обо мне».

Добавь:

  • имя;
  • несколько предложений о себе;
  • увлечения;
  • что хочешь научиться делать;

6. Меню должно работать

На всех трёх страницах: 

<nav>

    <a href="index.html">
        Главная
    </a>

    <a href="games.html">
        Игры
    </a>

    <a href="about.html">
        Обо мне
    </a>

</nav>
Проверь каждую ссылку. Нажми на неё и убедись, что открывается нужная страница.

7. Добавь изображения

Можно создать папку: 

images

Тогда структура: 

game-zone/

├── index.html
├── games.html
├── about.html
│
└── images/
    ├── game1.jpg
    └── game2.jpg

Подключение: 

<img
    src="images/game1.jpg"
    alt="Описание игры"
>

Проверка

☐ Есть index.html

☐ Есть games.html

☐ Есть about.html

☐ Есть <header>

☐ Есть <nav>

☐ Есть <main>

☐ Есть минимум два <section>

☐ Есть <footer>

☐ Меню работает на всех страницах

☐ Есть картинка

☐ У картинки есть alt

Покажи сайт преподавателю.

Если все страницы работают — переходи к дополнительному заданию.
