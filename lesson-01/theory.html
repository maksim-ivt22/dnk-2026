Занятие №1 — Первый сайт

Как работает сайт, что такое HTML и как создать свою первую веб-страницу.

Если ты пропустил первое занятие:

Пройди эту страницу сверху вниз, повторяй код у себя в VS Code и обязательно выполняй примеры.

1. Что такое сайт?

Сайт — это набор страниц, которые браузер показывает пользователю.

Например, браузеры:

  • Google Chrome
  • Firefox
  • Edge
  • Opera
  • Safari
Когда мы открываем сайт, браузер получает файлы сайта и отображает их на экране.

2. Из чего состоит сайт?

HTML Содержание страницы
CSS Внешний вид
JavaScript Поведение страницы
Можно представить человека:

HTML — скелет
CSS — внешний вид
JavaScript — действия

3. Сегодня изучаем HTML

HTML означает:

HyperText Markup Language

Это язык разметки веб-страниц.

HTML сообщает браузеру, что находится на странице.

Например: 

<h1>Привет!</h1>

Браузер понимает: это главный заголовок.

4. Что понадобится?

Для работы нам нужны:

  • VS Code;
  • браузер;
  • папка для проекта.

5. Создаём первый проект

Шаг 1

Создай на компьютере папку: 

first-site

Шаг 2

Открой эту папку в VS Code.

Шаг 3

Создай файл: 

index.html
Файл должен называться именно: index.html

Не: index.txt

6. Первый HTML-код

Напиши в файле: 

<!DOCTYPE html>

<html lang="ru">

<head>

    <meta charset="UTF-8">

    <title>Мой первый сайт</title>

</head>


<body>

    <h1>Привет!</h1>

    <p>Это мой первый сайт.</p>

</body>


</html>

7. Что означает этот код?

<!DOCTYPE html>

Сообщает браузеру, что это современный HTML-документ.

<html>

Начало всей HTML-страницы.

<head>

Здесь находится информация о странице.

<title>

Название вкладки браузера.

<body>

Здесь находится всё, что пользователь видит на странице.

<h1>

Главный заголовок.

<p>

Обычный абзац текста.

Главное для первого занятия:

<head> — информация о странице.
<body> — содержимое страницы.

8. Запускаем сайт

  1. Сохрани файл: Ctrl + S.
  2. Найди index.html.
  3. Открой его браузером.

Ты должен увидеть:

Привет!

Это мой первый сайт.

9. Самое важное действие разработчика

Изменил код
      ↓
Сохранил
      ↓
Обновил браузер
      ↓
Посмотрел результат

Попробуй

Замени: 

<h1>Привет!</h1>

на: 

<h1>Привет! Меня зовут Максим</h1>

Сохрани файл и обнови браузер.
