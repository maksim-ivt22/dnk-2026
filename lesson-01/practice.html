Практическая работа №1

Создаём свою первую HTML-страницу.

Задача

Создай страницу «Обо мне».

На странице должно быть:

  1. Название вкладки браузера.
  2. Главный заголовок с твоим именем.
  3. Абзац о себе.
  4. Ещё один заголовок.
  5. Ещё один абзац.

1. Создай папку

lesson-1-practice

2. Создай файл

index.html

3. Напиши базовую структуру

Если забыл структуру, можешь использовать эту подсказку. 
<!DOCTYPE html>

<html lang="ru">

<head>

    <meta charset="UTF-8">

    <title>
        __________________
    </title>

</head>


<body>



</body>


</html>

4. Добавь главный заголовок

Например: 

<h1>
    Привет! Меня зовут Максим
</h1>

Но напиши своё имя.

5. Напиши о себе

Используй: 

<p>
    Здесь текст о тебе.
</p>

Можно написать:

  • в каком классе ты учишься;
  • что тебе нравится;
  • почему ты пришёл на веб-программирование.

6. Добавь ещё один раздел

Например: 

<h2>
    Что я хочу научиться делать
</h2>

<p>
    Я хочу научиться создавать сайты.
</p>

Проверка

☐ Файл называется index.html

☐ Есть <title>

☐ Есть <h1>

☐ Есть <h2>

☐ Есть минимум два <p>

☐ Файл сохранён

☐ Страница открывается в браузере

Готово?

Покажи страницу преподавателю.

Если всё правильно — можешь перейти к дополнительному заданию.
