useEffect, API и fetch

React useEffect API fetch
Цель занятия: научиться получать данные из интернета и показывать их в React-приложении.

1. Что мы уже умеем?

На прошлых занятиях мы научились:

  • создавать компоненты;
  • использовать props;
  • работать с useState;
  • создавать массивы;
  • выводить элементы через map();
  • работать с формами.

2. Откуда ещё можно брать данные?

До этого данные находились прямо в нашем коде: 

const games = [
    {
        id: 1,
        title: "Elden Ring"
    }
];

Но настоящие сайты часто получают данные с сервера.

React ↓ запрос ↓ API ↓ данные ↓ React показывает данные

3. Что такое API?

API — способ, с помощью которого одна программа может получать данные от другой программы.

Например:

наш React-сайт ↓ просит список пользователей ↓ API ↓ возвращает данные пользователей

4. Что такое JSON?

Сервер часто возвращает данные в формате JSON. 

{
    "id": 1,
    "name": "Leanne Graham",
    "email": "example@example.com"
}

JSON похож на объект JavaScript.

5. Наш учебный API

Будем использовать: 

https://jsonplaceholder.typicode.com/users

Этот адрес возвращает список пользователей.

6. Что такое fetch()?

fetch() отправляет запрос. 

fetch("https://jsonplaceholder.typicode.com/users")

Но ответ приходит не мгновенно.

Поэтому используется: 

async
await

7. Простая функция загрузки

async function loadUsers() {

    const response = await fetch(
        "https://jsonplaceholder.typicode.com/users"
    );

    const data = await response.json();

    console.log(data);

}

Что происходит?

fetch() ↓ получили response ↓ response.json() ↓ получили JavaScript-данные

8. Где хранить полученные данные?

В useState. 

const [users, setUsers] = useState([]);

Сначала массив пустой: 

[]

После загрузки: 

setUsers(data);

9. Что такое useEffect?

useEffect позволяет выполнить код после появления компонента на странице.

Сначала импорт: 

import {
    useState,
    useEffect
} from "react";

Затем: 

useEffect(() => {

    console.log("Компонент появился");

}, []);

Что означает []?

Пустой массив зависимостей означает:

выполнить Effect при появлении компонента.

10. Загружаем пользователей

useEffect(() => {

    async function loadUsers() {

        const response = await fetch(
            "https://jsonplaceholder.typicode.com/users"
        );

        const data = await response.json();

        setUsers(data);

    }

    loadUsers();

}, []);

11. Почему функция находится внутри useEffect?

Сам callback useEffect не делаем напрямую async.

Поэтому внутри создаём: 

async function loadUsers() {

}

и вызываем: 

loadUsers();

12. Выводим данные через map()

{users.map(user => (

    <div key={user.id}>

        <h2>
            {user.name}
        </h2>

        <p>
            {user.email}
        </p>

    </div>

))}
Здесь соединяются две прошлые темы: API + map().

13. Состояние загрузки

Интернет может быть медленным.

Создадим: 

const [loading, setLoading] = useState(true);

После загрузки: 

setLoading(false);

В JSX: 

{loading && (
    <p>
        Загрузка...
    </p>
)}

14. Обработка ошибки

Иногда сервер недоступен.

Создадим: 

const [error, setError] = useState("");

Используем try / catch: 

try {

    const response = await fetch(
        "https://jsonplaceholder.typicode.com/users"
    );

    if (!response.ok) {
        throw new Error("Ошибка загрузки");
    }

    const data = await response.json();

    setUsers(data);

} catch (error) {

    setError("Не удалось загрузить данные");

}

15. finally

Независимо от результата, загрузка должна закончиться: 

finally {

    setLoading(false);

}

16. Полный пример

import {
    useEffect,
    useState
} from "react";


function App() {

    const [users, setUsers] = useState([]);

    const [loading, setLoading] = useState(true);

    const [error, setError] = useState("");


    useEffect(() => {

        async function loadUsers() {

            try {

                const response = await fetch(
                    "https://jsonplaceholder.typicode.com/users"
                );


                if (!response.ok) {
                    throw new Error("Ошибка");
                }


                const data = await response.json();

                setUsers(data);

            } catch (error) {

                setError(
                    "Не удалось загрузить пользователей"
                );

            } finally {

                setLoading(false);

            }

        }


        loadUsers();

    }, []);


    return (

        <div>

            <h1>
                Пользователи
            </h1>


            {loading && (
                <p>
                    Загрузка...
                </p>
            )}


            {error && (
                <p>
                    {error}
                </p>
            )}


            {users.map(user => (

                <div key={user.id}>

                    <h2>
                        {user.name}
                    </h2>

                    <p>
                        {user.email}
                    </p>

                </div>

            ))}

        </div>

    );

}


export default App;

17. Что происходит по шагам?

1. App запускается ↓
2. users = [] ↓
3. loading = true ↓
4. useEffect запускается ↓
5. fetch отправляет запрос ↓
6. API отвечает ↓
7. response.json() ↓
8. setUsers(data) ↓
9. React обновляет страницу ↓
10. map() создаёт карточки

18. Зависимости useEffect

Сейчас: 

useEffect(() => {

}, []);

Effect запускается при появлении компонента.

Но можно написать: 

useEffect(() => {

    console.log("Изменился userId");

}, [userId]);

Тогда Effect будет запускаться при изменении userId.

На первом занятии по useEffect достаточно понимать два варианта: [] и [значение].
