```html Практика №16 — GitHub Pages

Практическая работа №16

Публикуем собственный сайт через GitHub Pages

Задача

Возьми свой готовый HTML/CSS/JavaScript-проект и опубликуй его в интернете.

В конце занятия у тебя должны быть:
  • GitHub-репозиторий;
  • index.html;
  • включённый GitHub Pages;
  • работающий публичный адрес;
  • минимум одно обновление после публикации.

1. Выбери проект

Можно использовать:

  • сайт о себе;
  • Game Zone;
  • портфолио;
  • лендинг;
  • другой HTML/CSS/JS-проект.

2. Проверь структуру

my-site/

├── index.html
├── style.css
├── script.js
│
└── images/
    └── photo.jpg
Обязательно должен быть файл index.html.

3. Проверь сайт локально

Открой index.html в браузере.

Проверь:

  • картинки;
  • CSS;
  • ссылки;
  • JavaScript;
  • переходы между страницами.

4. Проверь Git

git status

5. Сохрани последние изменения

git add .

git commit -m "Подготовил сайт к публикации"

git push

6. Открой GitHub

Перейди в репозиторий проекта.

Убедись, что файлы появились на GitHub.

7. Открой Settings

В репозитории: 

Settings

8. Открой Pages

В левом меню найди: 

Pages

9. Настрой публикацию

В разделе: 

Build and deployment

выбери: 

Source:
Deploy from a branch

10. Выбери ветку

Branch:
main

Папка: 

/(root)

Нажми: 

Save

11. Найди адрес сайта

После публикации в разделе Pages появится ссылка.

Она будет похожа на: 

https://username.github.io/my-site/

12. Открой опубликованный сайт

Проверь:

  • загружается ли главная страница;
  • есть ли стили;
  • загружаются ли картинки;
  • работают ли ссылки.

13. Если CSS не работает

Проверь: 

<link
    rel="stylesheet"
    href="style.css"
>

Не используй без необходимости: 

href="/style.css"

14. Если картинка не работает

Проверь: 

<img
    src="images/photo.jpg"
    alt="Фото"
>
Проверь регистр букв в имени папки и файла.

15. Сделай первое обновление сайта

Измени заголовок: 

<h1>
    Мой опубликованный сайт
</h1>

Или добавь новый раздел.

16. Отправь обновление

git status

git add .

git commit -m "Обновил опубликованный сайт"

git push

17. Проверь сайт ещё раз

Открой адрес GitHub Pages и проверь изменение.

18. Добавь ссылку на GitHub

На сайт можно добавить: 

<a
    href="https://github.com/USERNAME/REPOSITORY"
    target="_blank"
>
    Репозиторий проекта
</a>

19. Добавь README.md

В репозитории создай: 

README.md

Например: 

# Game Zone

Учебный сайт о компьютерных играх.

## Использовано

- HTML
- CSS
- JavaScript

## Сайт

https://username.github.io/game-zone/

Проверка

Проект находится на GitHub

Есть index.html

Выбран Deploy from a branch

Выбрана ветка main

Выбрано /(root)

GitHub Pages включён

Получен публичный адрес

Сайт открывается

CSS работает

Картинки работают

Ссылки работают

После нового push сайт обновился

Есть README.md

Готово?

Покажи преподавателю:

  1. репозиторий GitHub;
  2. настройки Pages;
  3. открытый опубликованный сайт;
  4. историю commit.
```
